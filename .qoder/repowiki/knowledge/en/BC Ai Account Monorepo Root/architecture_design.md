The workspace is a flat monorepo with three sibling domains — `backend/` (Go API + microservices), `frontend/` (Next.js SSR app with API routes proxying to the backend), and `datamodel_docs/` (Markdown wiki generated from Go struct annotations). Cross-cutting concerns live at this level: `AGENTS.md` / `CLAUDE.md` / `GEMINI.md` define the multi-model orchestration contract (Opus 4.8 as orchestrator) that every agent reads identically; `.agents/rules`, `.agents/skills`, and `.agents/wiki` hold the shared rule/skill/knowledge base consumed by all children; `CODE-MAP.md` indexes large files across both `backend/` and `frontend/`; `tools/gen-code-map.ps1` regenerates it. The root also holds project-wide ignore lists (`.gitignore`, `.aiignore`, `.claudeignore`, `.ignore`) and MongoDB audit artifacts (`.mongo_all_cols.txt`, `.mongo_audit_out.txt`). Children communicate only through the backend's HTTP/Kafka surface — there is no cross-child import graph.
