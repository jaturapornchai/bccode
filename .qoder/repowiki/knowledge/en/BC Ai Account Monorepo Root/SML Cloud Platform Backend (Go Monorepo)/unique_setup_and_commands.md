Configuration is loaded from `bootstrap.json` (plus optional `custom_config.json`); `.env` is no longer used. Run modes are selected via `DEV_API_MODE=3` for migrations-only or `DEV_API_MODE=2` for HTTP-only. Development compose stacks live in `docker-compose.yml`, `docker-compose.local.yml`, `docker-compose.dev.yml`, and `cluster/docker-compose.yml`; per-service Dockerfiles are provided under `cmd/<svc>/Dockerfile` and top-level `Dockerfile*` variants.
