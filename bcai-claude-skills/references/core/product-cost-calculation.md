# การคำนวณต้นทุนสินค้า (Product Cost Calculation)

## วิธีคำนวณ: ต้นทุนเฉลี่ยถ่วงน้ำหนัก (Moving Weighted Average)

ระบบใช้วิธี **ต้นทุนเฉลี่ย** — ทุกครั้งที่ซื้อของเข้ามา ระบบจะ **หาค่าเฉลี่ยใหม่** ระหว่างของเก่ากับของใหม่

---

## เข้าใจง่ายๆ — ต้นทุนเฉลี่ยคืออะไร?

### ตัวอย่าง: ซื้อปากกา

| เหตุการณ์ | จำนวน | ราคา/ด้าม | มูลค่า | คงเหลือ | มูลค่าคงเหลือ | ต้นทุนเฉลี่ย |
|----------|--------|----------|--------|---------|---------------|-------------|
| ซื้อครั้ง 1 | +100 ด้าม | 10 บาท | 1,000 | 100 | 1,000 | **10.00** |
| ซื้อครั้ง 2 | +50 ด้าม | 12 บาท | 600 | 150 | 1,600 | **10.67** |
| ขายไป | -30 ด้าม | (ต้นทุน 10.67) | 320 | 120 | 1,280 | **10.67** |
| ซื้อครั้ง 3 | +80 ด้าม | 11 บาท | 880 | 200 | 2,160 | **10.80** |

### สูตร

```
ต้นทุนเฉลี่ย = มูลค่าคงเหลือ ÷ จำนวนคงเหลือ
```

**ซื้อเข้า (รับสินค้า):**
```
มูลค่าคงเหลือใหม่ = มูลค่าคงเหลือเดิม + มูลค่าที่ซื้อ (ราคาจริงก่อน VAT)
จำนวนคงเหลือใหม่ = จำนวนคงเหลือเดิม + จำนวนที่ซื้อ
ต้นทุนเฉลี่ยใหม่  = มูลค่าคงเหลือใหม่ ÷ จำนวนคงเหลือใหม่
```

**ขายออก / เบิกออก:**
```
มูลค่าที่ออก       = ต้นทุนเฉลี่ยปัจจุบัน × จำนวนที่ขาย
มูลค่าคงเหลือใหม่ = มูลค่าคงเหลือเดิม - มูลค่าที่ออก
จำนวนคงเหลือใหม่ = จำนวนคงเหลือเดิม - จำนวนที่ขาย
ต้นทุนเฉลี่ยใหม่  = มูลค่าคงเหลือใหม่ ÷ จำนวนคงเหลือใหม่
```

## Flow การคำนวณ — ทำงานยังไง?

```
 1. บันทึกเอกสาร (ซื้อ/ขาย/รับ/เบิก)
    → เก็บลง MongoDB
         │
         ▼
 2. ส่งข้อมูลผ่าน Kafka
    → Consumer รับ → เขียนลง PostgreSQL
    → เพิ่ม itemcode เข้า stockwaitprocess (คิวรอคำนวณ)
         │
         ▼
 3. คำนวณต้นทุน (Batch Processing)
    → ดึง transaction ทั้งหมดของสินค้า เรียงตาม วันที่ + ลำดับรายการ
    → วนทีละ transaction:
         │
         ├── ถ้าเป็น "เข้า" → ใช้ราคาซื้อจริง (SumAmount)
         ├── ถ้าเป็น "ออก" → ใช้ต้นทุนเฉลี่ย × จำนวน
         │
         ├── คำนวณ: ยอดคงเหลือ + มูลค่าคงเหลือ
         └── คำนวณ: ต้นทุนเฉลี่ยใหม่ = มูลค่าคงเหลือ ÷ ยอดคงเหลือ
         │
         ▼
 4. บันทึกผลลัพธ์
    → ตาราง processstockcost (ทุก transaction)
    → อัพเดท productbarcode (ต้นทุนเฉลี่ยล่าสุด)
    → เขียนไป ClickHouse (สำหรับ report)
```

## กรณีพิเศษ

### สินค้าหมด (ยอดคงเหลือ = 0)
```
→ บังคับ: มูลค่าคงเหลือ = 0, ต้นทุนเฉลี่ย = 0
→ ป้องกันไม่ให้เกิดมูลค่าค้าง (orphan value)
→ ซื้อเข้ามาใหม่ → ต้นทุนเริ่มจากราคาซื้อใหม่เลย
```

### ส่งคืน / รับคืน
```
→ ถ้ามีเอกสารอ้างอิง (DocRef) → ใช้ต้นทุนจากเอกสารเดิม
→ ถ้าไม่มี DocRef → ใช้ต้นทุนเฉลี่ยปัจจุบัน
```

### โอนย้ายคลัง (Transfer)
```
คลังต้นทาง (ออก): ใช้ต้นทุนเฉลี่ย × จำนวน
คลังปลายทาง (เข้า): รับต้นทุนเดียวกับที่ออก (ไม่คำนวณใหม่)
```

### หน่วยนับ (Multi-Unit)
```
สินค้า "น้ำดื่ม" ขายเป็น "โหล" แต่เก็บสต็อกเป็น "ขวด"
→ แปลงเป็นหน่วยมาตรฐานก่อนคำนวณ:
   จำนวนมาตรฐาน = จำนวน × (UnitStand ÷ UnitDivide)
   ตัวอย่าง: 2 โหล × (12 ÷ 1) = 24 ขวด
```

## ตาราง Database ที่เกี่ยวข้อง

### `productbarcode` (MongoDB + PostgreSQL) — ข้อมูลสินค้าปัจจุบัน

| Field | ความหมาย |
|-------|----------|
| `balanceqty` | จำนวนคงเหลือปัจจุบัน |
| `balanceamount` | มูลค่าคงเหลือปัจจุบัน |
| `averagecost` | ต้นทุนเฉลี่ยปัจจุบัน |

### `docdetail` (PostgreSQL) — รายละเอียดทุกเอกสาร

| Field | ความหมาย |
|-------|----------|
| `docdatetime` | วันเวลาเอกสาร (ใช้เรียงลำดับ) |
| `itemcode` | รหัสสินค้า |
| `transflag` | ประเภทเอกสาร (ดูตารางด้านบน) |
| `calcflag` | 1=เพิ่มสต็อก, 2=ลดสต็อก |
| `totalqty` | จำนวน (แปลงเป็นหน่วยมาตรฐานแล้ว) |
| `sumamount` | มูลค่ารวม (ราคาก่อน VAT) |

### `processstockcost` (PostgreSQL) — ผลการคำนวณต้นทุน

| Field | ความหมาย |
|-------|----------|
| `itemcode` | รหัสสินค้า |
| `transflag` | ประเภทเอกสาร |
| `totalqty` | จำนวนที่เปลี่ยน |
| `calcamount` | มูลค่าที่คำนวณ |
| `averagecost` | ต้นทุนเฉลี่ย ณ เวลานั้น |
| `balanceqty` | ยอดคงเหลือหลังคำนวณ |
| `balanceamount` | มูลค่าคงเหลือหลังคำนวณ |
| `unitcost` | ต้นทุนต่อหน่วย |

### `stock_transaction_detail` (PostgreSQL) — sync จาก MongoDB

| Field | ความหมาย |
|-------|----------|
| `costperunit` | ทุนต่อหน่วย |
| `totalcost` | ต้นทุนรวม |
| `balanceqty` | ยอดคงเหลือ |
| `balanceamount` | มูลค่าคงเหลือ |
| `balanceaverage` | ต้นทุนเฉลี่ยคงเหลือ |

## สรุปสั้นๆ

1. **ซื้อเข้า** → ใช้ราคาซื้อจริง → คำนวณต้นทุนเฉลี่ยใหม่
2. **ขายออก** → ใช้ต้นทุนเฉลี่ยปัจจุบัน × จำนวน
3. **ของหมด** → ต้นทุน reset เป็น 0
4. **ซื้อใหม่หลังของหมด** → ต้นทุน = ราคาซื้อใหม่เลย
5. **โอนย้าย** → ต้นทุนจากคลังต้นทางส่งต่อให้คลังปลายทาง
6. **ปรับต้นทุน** → เปลี่ยนมูลค่าโดยไม่เปลี่ยนจำนวน
