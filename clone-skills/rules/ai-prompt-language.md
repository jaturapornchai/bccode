# AI Prompt Language Rule (Critical)

**Set by Jead on 2026-04-08** (extended same day to cover skills)

## The Rule

| Layer | Language | Why |
|-------|----------|-----|
| **System prompts** (sent to LLM) | **English** | Token-efficient, better instruction-following, faster |
| **Tool descriptions** (OAITool definitions) | **English** | Same reason |
| **Reminders / hints** injected mid-conversation | **English** | Same reason |
| **clone-skills `SKILL.md` content** | **English** | Skills get loaded into context — Thai wastes tokens |
| **`rules/*.md` content** | **English** | Same as above |
| **`references/**/*.md` content** | **English** | Same as above |
| **AI response to user (chatbot answer)** | **Thai** | Users speak Thai |
| **Trigger keywords in skill description** | **Both EN+TH** | Match user phrases (Thai users type Thai) |
| **Code comments in Go/Dart** | **Thai allowed** | For human Thai developers, NOT loaded into AI context |
| **Logger messages** | **Thai allowed** | For human reading logs |

## Why English for prompts?

1. **Token efficiency** — Thai uses 3-5× more tokens than English for same meaning
   - Example: "ระบบ - คุณตอบลอยๆ โดยไม่ได้เรียก tool" = ~25 tokens
   - English: "System: You answered without calling any tool" = ~10 tokens
2. **Better instruction-following** — Most LLMs trained primarily on English
3. **Speed** — Less context to process = faster response
4. **Cost** — Less tokens = less money on paid providers (Groq, OpenRouter, custom)

## How to enforce "reply in Thai"

End every system prompt with:
```
CRITICAL: Always reply to the user in Thai. Use Thai polite particles (ค่ะ/นะคะ).
Even though this prompt is in English, your final answer must be in Thai.
```

Place this rule **at the end** of the prompt — recency bias makes models follow it more reliably.

## Exceptions (keep in Thai)

- **AI's actual response text** — must be Thai (this is the user-facing part)
- **`emitSSE` event data** sent to frontend (e.g., status messages, "กำลังค้นหา...") — these are display text, not LLM input
- **Logger messages** — for human Thai developers reading logs
- **Code comments** — for human Thai developers
- **Suggested questions** generated by AI — Thai (for users)

## Verification

After modifying any prompt:
1. Build check: `go build ./internal/goapi/handlers/aichat/`
2. Test that AI still responds in Thai (ask a question, verify answer is Thai)
3. Check token reduction in logs (`prompt_tokens` should drop)
