# OptionPatternItemGuid

โครงสร้าง `OptionPatternItemGuid` จากโมดูล mainapi `optionpattern` มีฟิลด์ตามซอร์ส `optionpattern.go`

| Field | Type | bson | json | คำอธิบาย |
|---|---|---|---|---|
| PatternCode | string | patterncode | patterncode | ค่าของ PatternCode ตามฟิลด์ `patterncode` ในซอร์ส |

## ความสัมพันธ์

- ไม่มีฟิลด์ที่ใช้ struct ซ้อนตามประกาศนี้
