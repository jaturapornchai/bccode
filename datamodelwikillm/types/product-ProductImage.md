# ProductImage

| Field | Type | bson | json | คำอธิบาย |
|---|---|---|---|---|
| XOrder | int | xorder | xorder | ลำดับการแสดงผล |
| URI | string | uri | uri | ค่าของ URI ตามฟิลด์ `uri` ในซอร์ส |

## ความสัมพันธ์
