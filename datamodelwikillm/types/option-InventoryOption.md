# InventoryOption

โครงสร้าง `InventoryOption` จากโมดูล mainapi `option` มีฟิลด์ตามซอร์ส `option.go`

| Field | Type | bson | json | คำอธิบาย |
|---|---|---|---|---|
| DocID | string | - | - | ค่าของ DocID ตามฟิลด์ `DocID` ในซอร์ส |
| OptID | string | - | - | ค่าของ OptID ตามฟิลด์ `OptID` ในซอร์ส |

## ความสัมพันธ์

- ไม่มีฟิลด์ที่ใช้ struct ซ้อนตามประกาศนี้
