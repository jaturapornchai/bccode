# MarketplacePayloadExample

โครงสร้าง `MarketplacePayloadExample` จากโมดูล mainapi `productbarcode` มีฟิลด์ตามซอร์ส `product_barcode.go`

| Field | Type | bson | json | คำอธิบาย |
|---|---|---|---|---|
| Direction | string | direction | direction | ค่าของ Direction ตามฟิลด์ `direction` ในซอร์ส |
| UseCase | string | usecase | usecase | ค่าของ UseCase ตามฟิลด์ `usecase` ในซอร์ส |
| Payload | any | payload | payload | ค่าของ Payload ตามฟิลด์ `payload` ในซอร์ส |

## ความสัมพันธ์

- ไม่มีฟิลด์ที่ใช้ struct ซ้อนตามประกาศนี้
