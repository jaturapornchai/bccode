## 1. ปรัชญาและโครงสร้างภาพรวม (Product Architecture & Philosophy)

**FlowAccount** ถูกสร้างขึ้นภายใต้แนวคิด **"โปรแกรมบัญชีที่คนทำธุรกิจใช้งานได้จริง โดยไม่ต้องมีความรู้ด้านบัญชี"**
- สถาปัตยกรรมเน้นความเรียบง่าย (Simplicity-First)
- UI จำลองแบบฟอร์มเอกสารกระดาษที่คุ้นเคย (WYSIWYG Document Editor)
- บันทึกบัญชีแบบอัตโนมัติเบื้องหลัง (Hidden Accounting Complexity) ผู้ใช้กรอกแค่เอกสารซื้อ-ขาย ระบบจะแปลงเป็นเดบิต-เครดิตให้อัตโนมัติ

## 2. ฟังก์ชันและโมดูลงานอย่างละเอียด

### 2.1 การจัดการงานขายและรายได้ (Sales & Invoicing)
- **วงจรเอกสารการขาย (Sales Lifecycle)**:
  - `ใบเสนอราคา (Quotation)` → `ใบวางบิล / ใบแจ้งหนี้ (Billing Note / Invoice)` → `ใบเสร็จรับเงิน / ใบกำกับภาษี (Receipt / Tax Invoice)` → `ใบลดหนี้ (Credit Note)`
  - รองรับการแปลงสถานะเอกสารแบบ 1-Click (เช่น กดปุ่มแปลงใบเสนอราคาเป็นใบแจ้งหนี้)
- **การพิมพ์และส่งเอกสาร**:
  - รองรับการส่งเอกสารเป็นลิงก์ดิจิทัล หรือส่งทาง Email, LINE, และดาวน์โหลด PDF
  - มีระบบ **Status Tracker** ตรวจสอบว่าลูกค้าเปิดดูเอกสารแล้วหรือยัง
- **ระบบรับชำระเงินดิจิทัล (FlowPay / Payment Gateway)**:
  - สร้าง QR Code พร้อมเพย์บนหัวบิลเพื่อให้ลูกค้าสแกนจ่ายได้ทันที
  - เชื่อมต่อ Payment Gateway (เช่น Stripe, Omise, GB Prime Pay) เพื่อรับบัตรเครดิต และอัปเดตสถานะเป็น "ชำระเงินแล้ว" อัตโนมัติ

### 2.2 การจัดซื้อและค่าใช้จ่าย (Purchases & Expenses)
- **เอกสารการซื้อ**:
  - `ใบสั่งซื้อ (Purchase Order - PO)` → `บันทึกค่าใช้จ่าย / ใบรับสินค้า (Expense Record / Goods Receipt)`
  - รองรับการหักภาษี ณ ที่จ่ายตามประเภทบริการ (1%, 2%, 3%, 5%)
- **AutoKey (AI OCR สแกนบิลและใบเสร็จ)**:
  - ใช้เทคโนโลยี AI OCR สแกนรูปถ่ายบิลค่าน้ำมัน, สลิปโอนเงิน, ใบเสร็จ 7-Eleven, หรือไฟล์ PDF
  - ระบบดึงข้อมูล: ชื่อผู้ขาย, เลขประจำตัวผู้เสียภาษี, วันที่, ยอดเงินรวม, ยอด VAT มากรอกลงฟอร์มบันทึกค่าใช้จ่ายให้อัตโนมัติ
  - ลดเวลาการคีย์เอกสารของฝ่ายบัญชีลงมากกว่า 70%

### 2.3 ระบบสินค้า สต็อก และคลังสินค้า (Inventory & Warehouse)
- **ประเภทสินค้า**:
  - รองรับทั้ง `สินค้าที่นับสต็อก (Physical Inventory)`, `บริการ (Service)`, และ `สินค้าที่ไม่นับสต็อก`
  - รองรับหน่วยนับสินค้าหลายระดับ (Multi-Units) เช่น ชิ้น, โหล, กล่อง, ลัง
- **คลังสินค้า (Multi-Warehouse)**:
  - รองรับการสร้างคลังสินค้าได้สูงสุด 50 คลังต่อบริษัท
  - มีระบบ **โอนย้ายสินค้าระหว่างคลัง (Stock Transfer)**
  - บันทึกการปรับยอดสต็อก (Stock Adjustment) สำหรับกรณีสินค้าชำรุด สูญหาย หรือตรวจนับปลายงวด
- **การตัดสต็อกและต้นทุน**:
  - ตัดสต็อกอัตโนมัติตามเอกสารขาย (เมื่อออกใบกำกับภาษีหรือใบส่งของ)
  - คำนวณต้นทุนสินค้าตาม **วิธีถัวเฉลี่ยถ่วงน้ำหนัก (Moving Average Cost)**

### 2.4 ระบบบัญชีและการลงรายการ (Accounting & Journals)
- **สมุดรายวันอัตโนมัติ 5 เล่ม**:
  1. `สมุดรายวันขาย (Sales Journal - SV)`: บันทึกเมื่อเกิดการขายเชื่อ/เปิดใบกำกับภาษี
  2. `สมุดรายวันรับ (Receipt Journal - RV)`: บันทึกเมื่อเก็บเงินสด/โอนเงินเข้าธนาคาร
  3. `สมุดรายวันซื้อ (Purchase Journal - UV)`: บันทึกเมื่อซื้อสินค้าเชื่อหรือตั้งหนี้ค่าใช้จ่าย
  4. `สมุดรายวันจ่าย (Payment Journal - PV)`: บันทึกเมื่อจ่ายชำระหนี้หรือค่าใช้จ่าย
  5. `สมุดรายวันทั่วไป (General Journal - JV)`: สำหรับปรับปรุงบัญชี ค่าเสื่อมราคา หรือรายการกลับรายการ
- **ผังบัญชี (Chart of Accounts)**:
  - มีผังบัญชีมาตรฐานสำหรับธุรกิจไทยให้เลือกใช้ หรือสร้างรหัสบัญชีเพิ่มเติมได้
- **รายงานทางการเงิน (Financial Statements)**:
  - งบทดลอง (Trial Balance)
  - งบกำไรขาดทุน (Income Statement)
  - งบแสดงฐานะการเงิน / งบดุล (Balance Sheet)
  - งบกระแสเงินสด (Cash Flow Statement)

### 2.5 ระบบภาษีและ e-Tax (Tax Compliance)
- **ภาษีมูลค่าเพิ่ม (VAT)**:
  - รายงานภาษีขาย (Sales Tax Report)
  - รายงานภาษีซื้อ (Purchase Tax Report) พร้อมตรวจสอบบิลภาษีซื้อต้องห้าม
  - สรุปแบบยื่น ภ.พ.30 พร้อมส่งออกไฟล์ Excel หรือพิมพ์ฟอร์มสรรพากร
- **ภาษีหัก ณ ที่จ่าย (Withholding Tax)**:
  - ออกหนังสือรับรองการหักภาษี ณ ที่จ่าย (ใบ 50 ทวิ) พร้อมพิมพ์หรือส่งอีเมล
  - สรุปแบบยื่น ภ.ง.ด.3 (บุคคลธรรมดา) และ ภ.ง.ด.53 (นิติบุคคล) พร้อมไฟล์ Text ยื่น e-Filing
  - รองรับการเชื่อมต่อระบบ **e-Withholding Tax**
- **e-Tax Invoice by Time Stamp**:
  - ออกใบกำกับภาษีอิเล็กทรอนิกส์ที่มีการประทับรับรองเวลา (Time Stamp) ผ่านระบบของ ETDA/สพธ.
  - ส่งเอกสารให้ลูกค้าผ่านทางอีเมลโดยตรง ได้รับการรับรองตามกฎหมายสรรพากร

### 2.6 การเงินและการกระทบยอดธนาคาร (Banking & Reconciliation)
- **Bank Feed & Statement Import**:
  - นำเข้า Statement ธนาคาร (ผ่านไฟล์ Excel/CSV หรือ API บางธนาคาร เช่น กสิกรไทย K-Bank, SCB)
- **Smart Bank Reconciliation**:
  - ระบบช่วยจับคู่รายการเงินเข้า-ออกใน Statement กับบิลในระบบบัญชีโดยอัตโนมัติ
  - จับคู่ตามจำนวนเงิน วันที่ และเลขอ้างอิง

### 2.7 ระบบเงินเดือน (FlowPayroll)
- ออกแบบแยกเป็นโมดูลเงินเดือน แต่เชื่อมต่อข้อมูลการลงบัญชีกับ FlowAccount อัตโนมัติ
- คำนวณเงินเดือน, โอที, เบี้ยเลี้ยง, ประกันสังคม และภาษีหัก ณ ที่จ่าย (ภ.ง.ด.1)
- ออกสลิปเงินเดือน (Payslip) ให้พนักงานทางอีเมล
- สร้างไฟล์โอนเงินเดือนธนาคาร (Payroll Text File) และไฟล์ยื่นประกันสังคม (สปส.1-10)

### 2.8 การเชื่อมต่อและระบบนิเวศ (Ecosystem & Open API)
- **e-Commerce & POS Integration**:
  - เชื่อมต่อคำสั่งซื้อจาก Shopee, Lazada, TikTok Shop และระบบ POS ต่างๆ
  - ดึงข้อมูลยอดขายและค่าธรรมเนียมแพลตฟอร์มมาบันทึกบัญชีอัตโนมัติ
- **FlowAccount Open API (REST API)**:
  - มี RESTful API สำหรับนักพัฒนาภายนอก: Contacts, Products, Quotations, Invoices, Receipts, Expenses
  - Authentication: Bearer Token / API Key
  - จุดสังเกต: เน้นการเรียก Request ตรง (Polling / Direct Call) ยังไม่มีระบบ Webhook สาธารณะแบบยืดหยุ่น

## 3. สรุปการประเมิน FlowAccount

### จุดแข็ง (Strengths)
1. **User Experience ดีเยี่ยม**: หน้าจอเข้าใจง่ายที่สุด ไม่ข่มขวัญผู้ใช้งาน เจ้าของธุรกิจ 40+ สามารถออกบิลได้ทันทีโดยไม่ต้องผ่านการอบรม
2. **AutoKey OCR ทำงานได้จริง**: สแกนบิลและสลิปได้แม่นยำ ช่วยลดความเหนื่อยล้าในการคีย์ข้อมูลของ SME
3. **FlowPayroll ครบวงจร**: การมีระบบคิดเงินเดือนที่รวมภาษีหัก ณ ที่จ่าย ภ.ง.ด.1 และประกันสังคม ถือเป็นจุดขายสำคัญที่ SME ไทยต้องการ
4. **Mobile Experience แข็งแกร่ง**: มีแอปมือถือทั้ง iOS และ Android สามารถเปิดบิลหน้าร้าน พิมพ์ใบเสร็จผ่าน Bluetooth Printer พกพาได้ทันที

### ข้อจำกัด (Limitations)
1. **ไม่เหมาะกับธุรกิจผลิตที่มี BOM ซับซ้อน**: สต็อกเน้นซื้อมาขายไป ไม่รองรับการคำนวณต้นทุนการผลิตหลายขั้นตอน
2. **วิธีคำนวณต้นทุนมีเฉพาะ Average**: ไม่รองรับ FIFO หรือการคำนวณต้นทุนขายย้อนหลังเมื่อบิลซื้อเข้ามาช้า
3. **การจัดการหลายบริษัท (Holding) ยังแยกบัญชีกัน**: ไม่มีระบบ Holding กลางที่บริหารจัดการสินค้าหรือผู้ใช้ร่วมกันแบบ Single-Sign-On Multi-Tenant แท้จริง
4. **ระบบสิทธิ์ไม่ละเอียด**: กำหนดสิทธิ์ได้เป็น Role กว้างๆ (Admin, Accountant, Staff) ไม่สามารถคุมสิทธิ์รายปุ่มหรือรายหน้าจอได้
