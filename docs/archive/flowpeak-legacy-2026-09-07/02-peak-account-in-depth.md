## 1. ปรัชญาและโครงสร้างภาพรวม (Product Architecture & Philosophy)

**PEAK Account (PeakEngine)** ถูกสร้างขึ้นภายใต้แนวคิด **"โปรแกรมบัญชีออนไลน์ที่ตอบโจทย์ทั้งผู้ประกอบการและนักบัญชีมืออาชีพ เพื่อการเติบโตอย่างเป็นระบบ"**
- สถาปัตยกรรมเน้นความถูกต้องทางบัญชี (Accounting Integrity & Compliance)
- มีความยืดหยุ่นสูงในระดับบัญชีแยกประเภท (General Ledger) และผังบัญชี
- ใช้โครงสร้าง Multi-Product: `PEAK Account` (บัญชีหลัก), `PEAK Payroll` (เงินเดือน), `PEAK Tax` (ภาษี), `PEAK Asset` (สินทรัพย์), และ `PEAK Board` (วิเคราะห์ข้อมูล)
- มี Open API สถาปัตยกรรมระดับ Enterprise พร้อมระบบ Asynchronous Queue และ Webhook

## 2. ฟังก์ชันและโมดูลงานอย่างละเอียด

### 2.1 วงจรเอกสารธุรกิจ (Business Transactions Lifecycle)
- **วงจรงานขาย (Sales Lifecycle)**:
  - `ใบเสนอราคา (Quotation)` → `ใบสั่งขาย (Sales Order)` → `ใบแจ้งหนี้ / ใบกำกับภาษี (Invoice / Tax Invoice)` → `ใบวางบิล (Billing Note)` → `ใบเสร็จรับเงิน (Receipt)` → `ใบลดหนี้ (Credit Note)`
  - รองรับทั้งเอกสารประเภทมีภาษี (VAT 7%), ยกเว้นภาษี (VAT 0%), และไม่คิดภาษี
- **วงจรงานซื้อและค่าใช้จ่าย (Purchase & Expense Lifecycle)**:
  - `ใบสั่งซื้อ (Purchase Order - PO)` → `บันทึกค่าใช้จ่าย / ใบรับสินค้า (Expense Record)` → `ใบรับวางบิล (Billing Note Expense)` → `ใบจ่ายชำระเงิน (Payment)` → `ใบลดหนี้ค่าใช้จ่าย (Credit Note Expense)`
- **ฟังก์ชัน All-In-One (ลดขั้นตอนสร้างเอกสาร)**:
  - รองรับการสร้างเอกสารและรับ/จ่ายชำระเงินในครั้งเดียว (เช่น `Create Invoice All In One` จะสร้างทั้ง Invoice + Record Payment + Post บัญชี + ส่ง e-Tax ทันที)
- **ระบบสถานะเอกสารและการอนุมัติ (Approval Workflow)**:
  - มีสถานะ: `Draft (ร่าง)` → `Waiting Approval (รออนุมัติ)` → `Approved (อนุมัติแล้ว)` → `Paid (ชำระแล้ว)` → `Void (ยกเลิก)`
  - ป้องกันการแก้ไขเอกสารที่ผ่านการอนุมัติหรือชำระเงินแล้ว

### 2.2 ระบบบัญชีคู่ระดับมืออาชีพ (Professional Double-Entry GL)
- **การลงบัญชีแบบ Real-Time (Perpetual Posting)**:
  - ทุกเอกสารที่เกิดขึ้นในระบบ จะทำการบันทึกบัญชีคู่ (Debit / Credit) ลงสมุดรายวันอัตโนมัติทันที
  - สามารถกดดู "การลงบันทึกบัญชี" ใต้เอกสารทุกใบเพื่อตรวจสอบผังบัญชีที่ระบบลงให้
- **การปรับแต่งการลงบัญชีอิสระ**:
  - นักบัญชีสามารถแก้ไขรายการเดบิต/เครดิต หรือเพิ่มแถวบัญชีที่ต้องการปรับปรุงได้โดยตรง
  - สมุดรายวันทั่วไป (Daily Journal - JV) สำหรับบันทึกรายการปรับปรุงสิ้นงวด
- **การปิดงวดบัญชีและการล็อค (Lock by Period)**:
  - มีระบบ **Lock Period** เพื่อป้องกันไม่ให้ผู้ใช้งานทั่วไปแก้ไขหรือสร้างเอกสารย้อนหลังในงวดบัญชีที่ปิดยอดหรือตรวจสอบไปแล้ว
  - ระบบจะคืน Error ทันทีเมื่อมีการพยายามแตะต้องข้อมูลในงวดที่ล็อคไว้

### 2.3 ระบบสินค้า สต็อก และต้นทุนสินค้า FIFO อัตโนมัติ (Inventory & FIFO Costing)
- **วิธีคำนวณต้นทุนแบบเข้าก่อน-ออกก่อน (FIFO - First In, First Out)**:
  - คำนวณต้นทุนขาย (Cost of Goods Sold - COGS) ตามล็อตที่ซื้อเข้ามาจริงแบบ FIFO
  - ทำให้มูลค่าสินค้าคงเหลือในงบดุลสะท้อนราคาตลาดล่าสุดอย่างถูกต้องตามมาตรฐานบัญชีไทย (TFRS for NPAEs / TFRS)
- **Perpetual Inventory Tracking**:
  - เมื่อมีการขาย บันทึก `Dr. ต้นทุนขาย / Cr. สินค้าคงเหลือ` ให้อัตโนมัติทันที
- **ระบบคำนวณต้นทุนขายใหม่ (Recalculate Cost Engine)**:
  - จุดเด่นสำคัญ: เมื่อเกิดกรณีที่ผู้ใช้บันทึกใบซื้อสินค้าย้อนหลัง ทำให้ลำดับ FIFO เดิมคลาดเคลื่อน ระบบมีปุ่ม **"คำนวณต้นทุนขายใหม่"** เพื่อกวาดคำนวณล็อตต้นทุนย้อนหลังทั้งงวดให้กลับมาถูกต้องสมบูรณ์
- **การจัดการสต็อกและคลังสินค้า**:
  - รองรับสินค้าหลายหน่วยนับ, จุดสั่งซื้อซ้ำ (Reorder Point), การปรับปรุงสต็อก (Stock Adjustment), และการโอนย้ายคลัง

### 2.4 ระบบสินทรัพย์ถาวร (PEAK Asset)
- **ทะเบียนสินทรัพย์ถาวร (Asset Register)**:
  - บันทึกรหัสสินทรัพย์, วันที่ซื้อ, มูลค่าราคาทุน, มูลค่าซาก, และอายุการใช้งาน (ปี)
  - เชื่อมโยงอัตโนมัติเมื่อมีการเปิดบิลซื้อทรัพย์สินใน PEAK Account
- **คำนวณค่าเสื่อมราคาอัตโนมัติ (Automated Depreciation)**:
  - คำนวณค่าเสื่อมราคาแบบเส้นตรง (Straight-Line) รายเดือนอัตโนมัติ
  - ลงรายการบัญชี `Dr. ค่าเสื่อมราคา / Cr. ค่าเสื่อมราคาสะสม` ลงสมุดรายวันทั่วไป (JV) ให้โดยอัตโนมัติในวันสิ้นเดือน
  - แสดงตารางค่าเสื่อมราคาตลอดอายุการใช้งาน

### 2.5 ระบบภาษีครบวงจร (PEAK Tax & e-Tax)
- **รายงานภาษีมูลค่าเพิ่ม**:
  - ภาษีซื้อ, ภาษีขาย, ภาษีซื้อไม่ถึงกำหนด, ภาษีซื้อต้องห้าม
  - แบบ ภ.พ.30 สรุปยอดภาษีที่ต้องชำระหรือขอคืน
- **ภาษีหัก ณ ที่จ่าย**:
  - ภ.ง.ด.1 (เงินเดือน), ภ.ง.ด.2 (ดอกเบี้ย/เงินปันผล), ภ.ง.ด.3 (บุคคล), ภ.ง.ด.53 (นิติบุคคล)
  - หนังสือรับรองหัก ณ ที่จ่าย 50 ทวิ พร้อมส่งออกไฟล์ Text ส่งสรรพากร
- **e-Tax Invoice & e-Receipt ครบวงจร**:
  - รองรับทั้งแบบ **e-Tax by Email** (ประทับเวลารับรอง) และ **e-Tax by Host / API** (ลงลายมือชื่อดิจิทัล Digital Signature ด้วยใบรับรองอิเล็กทรอนิกส์ XML & PDF/A-3)
  - ส่งเอกสาร e-Tax ให้คู่ค้าอัตโนมัติผ่านระบบและผ่าน API

### 2.6 การเงินและการกระทบยอดธนาคารอัตโนมัติ (Banking & Reconciliation)
- **ผูกบัญชีธนาคารหลายบัญชีและเงินสดย่อย (Petty Cash)**
- **Automated Bank Reconciliation**:
  - นำเข้า Statement (Excel/CSV หรือเชื่อมต่อธนาคาร)
  - อัลกอริทึมจับคู่รายการเงินเข้า/ออกกับเอกสารในระบบ พร้อมระบุค่าธรรมเนียมธนาคารให้อัตโนมัติ

### 2.7 การบริหารและการวิเคราะห์ข้อมูล (PEAK Board & Analytics)
- **Financial BI Dashboard**:
  - แสดงกระแสเงินสดเข้า-ออก, แนวโน้มกำไรสุทธิ, การคาดการณ์กระแสเงินสด (Cash Flow Forecasting)
  - สรุปยอดลูกหนี้ค้างชำระ (Aging Report: 30, 60, 90 วัน) และเจ้าหนี้ที่ถึงกำหนดจ่าย
- **Classification Groups & Tags (การจัดประเภทตามมิติ)**:
  - รองรับการติดป้าย Tag ในระดับเอกสารหรือแถวรายการสินค้า
  - วิเคราะห์งบกำไรขาดทุนแยกตาม **โครงการ (Project)**, **แผนก (Department)**, หรือ **สาขา (Branch)**

### 2.8 การเชื่อมต่อระดับองค์กร (PEAK Open API & Developer Platform)
- **สถาปัตยกรรม API สมบูรณ์แบบ**:
  - RESTful API รองรับการสร้างและอ่านเอกสารทุกชนิด (Contacts, Products, Invoices, Receipts, Expenses, Journals, Financial Reports)
- **Asynchronous Queue & Priority Queue**:
  - สำหรับระบบที่มี Transaction สูง (เช่น e-Commerce มียอดพันออเดอร์ต่อวัน) มีเอนด์พอยต์แบบ Queue (`/post_api-v1-invoices-queue`) เพื่อรับโหลดเร็ว ไม่ติด timeout แล้วประมวลผลเบื้องหลัง
- **Webhook Events แบบ Real-Time**:
  - รองรับการส่ง Event แจ้งเตือนระบบภายนอกเมื่อเกิดการเปลี่ยนแปลง: `Quotation`, `PurchaseOrder`, `Invoice`, `Expense`, `Receipt`, `Product`, `Contact`, `PaymentMethod`
- **PEAK Connect**:
  - ฟังก์ชันถ่ายรูปใบเสร็จส่งผ่าน LINE เพื่อส่งข้อมูลเข้าสู่ระบบ

## 3. สรุปการประเมิน PEAK Account

### จุดแข็ง (Strengths)
1. **มาตรฐานบัญชีเข้มงวดและสมบูรณ์ที่สุด**: ถูกใจสำนักงานบัญชีและผู้สอบบัญชี (CPA) เพราะการลงเดบิต/เครดิตเป๊ะ ล็อคงวดได้
2. **ระบบต้นทุน FIFO แท้จริง**: มีความสามารถในการคำนวณต้นทุนสินค้าแบบ FIFO ที่แม่นยำ และมีฟังก์ชันคำนวณย้อนหลังเมื่อบิลซื้อมาช้า
3. **PEAK Asset คิดค่าเสื่อมอัตโนมัติ**: ประหยัดเวลานักบัญชี ไม่ต้องคอยคำนวณค่าเสื่อมใน Excel แล้วมาคีย์มือทุกเดือน
4. **Developer Platform ทันสมัยมาก**: มีเอกสาร OpenAPI ละเอียด มี Queue รองรับโหลดสูง มี Webhook ให้เชื่อมต่อสองทางสมบูรณ์
5. **PEAK Board วิเคราะห์มิติ**: รองรับการดูงบแยกโครงการ/สาขาผ่านระบบ Tags

### ข้อจำกัด (Limitations)
1. **ความซับซ้อนของหน้าจอ (Steep Learning Curve)**: มีช่องกรอกข้อมูลและการตั้งค่าเยอะ ผู้ประกอบการทั่วไปที่ไม่รู้บัญชีอาจสับสนหรือกลัวกดผิด
2. **ราคาสูงกว่าคู่แข่ง**: แพ็กเกจราคาสูงกว่า FlowAccount และมีเงื่อนไขจำกัดจำนวนผู้ใช้งาน
3. **คิดค่าบริการ API เป็นราย Transaction (Billable POST)**: หากมีระบบภายนอกเชื่อมต่อยิงบิลเข้ามาเป็นจำนวนมาก จะมีค่าใช้จ่าย API เครดิตเพิ่มเติม
4. **ระบบ Multi-Tenant ระดับ Holding ยังไม่ไร้รอยต่อ**: แม้จะรองรับหลายกิจการ แต่นักพัฒนายังต้องสลับบริษัทและจัดการ User Token แยกกัน
