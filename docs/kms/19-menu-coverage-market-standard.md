# ความครบของเมนู BC เทียบมาตรฐานโปรแกรมบัญชีชั้นนำในตลาด
> ตรวจผังล่าสุด: 2026-09-11 — [เมนูอัปเกรดจาก Champ](decisions/2026-09-11-champ-upgrade-menu-workflows.md); เนื้อหาเทียบเคียงตลาดด้านล่างเป็นประวัติรอบ 2026-09-08

## สรุปผล

ผังปัจจุบันมี **223 เมนู / 9 ระบบ** (154 เดิม + 69 จากกระบวนการ Champ) เก็บ id/route เดิมครบ; **211 รอพัฒนา / 12 มีตัวเปิดหน้าจอ** ดู [ผังทั้งหมด](snippets/champ-upgrade-menu-map.md) และ [ผลเทียบต้นทาง/ข้อจำกัด](decisions/2026-09-11-champ-upgrade-menu-workflows.md) — ไม่ใช่การรับรองว่ารายงานทุกแบบหรือธุรกรรมทั้งหมดเทียบเท่าระบบเดิมแล้ว

> ⚠️ **อย่าเขียนว่า "ครบ 100%"** — ความครบขึ้นกับขอบเขตทางธุรกิจ โดยครอบคลุมงานหลักทั้งหมด (ล็อต/วันหมดอายุ, ใบรวมจ่าย/ใบเสร็จรวม, บัตรเครดิตกิจการ, เงินทดรองจ่ายกรรมการ, ซื้อสินทรัพย์/งานระหว่างก่อสร้าง/ตารางสินทรัพย์, ภาษีเงินได้รอการตัดบัญชี, เชื่อมต่อ LINE, สำรองข้อมูล, ส่งรายงานอัตโนมัติ — ส่วนบุคลากรและผู้ใช้งานจัดการที่ระดับ Holding/Workspace wizard ไม่ใช่เมนูหลักประจำวัน) และมีกลุ่มฟังก์ชันเฉพาะตัวของระบบ (POS/ร้านอาหาร, BOQ, marketplace, ชั้นต้นทุน FIFO, สินค้าชุด/BOM, เลขเครื่อง/serial, ทางลัดผู้ใช้)

**ข้อยกเว้นที่ตั้งใจไม่ทำ: ระบบเงินเดือน (payroll)** — ลุงจืดตัดสินใจ 2026-09-08 ว่า **ไม่เอาระบบเงินเดือน** ดังนั้น BC จะไม่มีโมดูลเงินเดือน และไม่มีแบบยื่นที่เกิดจากเงินเดือน (ภ.ง.ด.1 / ภ.ง.ด.1ก, ไฟล์นำส่งเงินสมทบประกันสังคม สปส. / กท.20 ก) — ถือเป็นความต่างที่ยอมรับแล้ว ไม่ใช่ช่องว่างที่ต้องปิด **ห้าม AI ตัวใดเพิ่มเมนูเงินเดือนกลับเข้ามาเองอีก**

**"มีเมนู" ≠ "ทำงานได้"** — ป้ายและการเปิดหน้าตรวจจาก `frontend/src/lib/menu-screen-status.ts`; หน้า pending ใช้ข้อความไทยสำหรับผู้ใช้ ไม่แสดง route/Flutter/Next.js ใน `frontend/src/app/menu/main-menu-screen.tsx:2836` รายละเอียดด้านล่างเก็บไว้เป็นประวัติ ไม่ใช่ยอดเมนูปัจจุบัน

1. **จัดการล็อตและวันหมดอายุ** (`/inventory/lotexpiry`): จัดการล็อตสินค้าและวันหมดอายุ (งานประจำ › คลังสินค้า)
2. **ความเคลื่อนไหวล็อตสินค้า** (`/report/stocklotmovement`): รายงานการเคลื่อนไหวตามล็อตต้นทุน/ล็อตสินค้า (รายงาน › สินค้า)
3. **สินค้าใกล้หมดอายุ** (`/report/expiringstock`): รายงานเตือนสินค้าใกล้ถึงวันหมดอายุ (รายงาน › สินค้า)

### ชุดล่าสุด (6 รายการ, commit `098107e1`) — จากการกวาดแหล่งข้อมูล Best Practices:
1. **แบบยื่น ภ.ง.ด.2** (`/report/vatpnd2`): ภาษีหัก ณ ที่จ่ายเงินได้ 40(3)/(4) — ดอกเบี้ย เงินปันผล ค่าสิทธิ ที่จ่ายให้บุคคลธรรมดา (รายงาน › รายงานภาษี) — ยืนยันกับกรมสรรพากร `https://efiling.rd.go.th` ที่ระบุแบบ ภ.ง.ด.1/2/3/53 คู่กัน · **ไม่ใช่เมนูเงินเดือน** ต้นทางคือรายการจ่ายเงิน ต่างจาก ภ.ง.ด.1 ที่ยังตัดออก
2. **กำไรขาดทุนตามสาขาและแผนก** (`/report/dimensionpnl`): งบกำไรขาดทุนแยกตามมิติสาขา/แผนก (รายงาน › รายงานการเงิน) — ใช้มิติที่มีอยู่แล้ว: กลุ่ม "มิติข้อมูล" (`/dimensions/projects`, `/dimensions/tags`, `/dimensions/boq` — `frontend/src/lib/menu-data.ts:322-329`) กับจอตั้งค่า `/department` และ `/branch`; **ห้ามสับสนกับ `/dimension`** ซึ่งเป็น backend basePath ของจอ `productdimension` (ขนาด/มิติสินค้า — `frontend/src/lib/system-setting-screens.ts:1633-1652`)
3. **ดึงคำสั่งซื้อจากร้านค้าออนไลน์** (`/transaction/marketplaceorder`): นำเข้าคำสั่งซื้อจากมาร์เก็ตเพลสมาเปิดเอกสารขาย (งานประจำ › ขาย)
4.-6. **เชื่อม Shopee / Lazada / TikTok** (`/marketplace/shopee|lazada|tiktok`): กลุ่มใหม่ "เชื่อมข้อมูลตลาดออนไลน์" (ข้อมูลหลัก) — **จอทั้งสามมีอยู่จริงและทำงานได้อยู่แล้ว** ที่ `frontend/src/app/menu/marketplace-screen.tsx` แต่ไม่มีเมนูชี้จึงเปิดไม่ได้ (`onOpenRoute` ที่ `main-menu-screen.tsx:1453-1455` เปิดได้เฉพาะ route ที่อยู่ในเมนู) รอบนี้ต่อสายเมนูให้ใช้ได้จริง

## บทเรียน: จอกำพร้า (screen ที่ไม่มีเมนูชี้)

`onOpenRoute` (`frontend/src/app/menu/main-menu-screen.tsx:1453-1455`) เปิดแท็บได้เฉพาะ route ที่มีรายการในเมนูเท่านั้น — จอที่เขียนเสร็จแล้วแต่ไม่มีเมนู = ผู้ใช้เข้าไม่ถึง และ test ไม่จับให้ ตรวจซ้ำได้ด้วย:

```bash
# route ของจอจริง = ที่ main-menu-screen dispatch (activeTab.route === "...") + route ของ system-setting slug
grep -ohE 'activeTab\.route === "[^"]+"' frontend/src/app/menu/main-menu-screen.tsx | grep -oE '"/[^"]+"' | tr -d '"' > /tmp/screens.txt
grep -ohE '^\s*route: "[^"]+"' frontend/src/lib/system-setting-screens.ts | grep -oE '"/[^"]+"' | tr -d '"' >> /tmp/screens.txt
sort -u /tmp/screens.txt -o /tmp/screens.txt
grep -oE '"/[^"]+"' frontend/src/lib/menu-data.ts | tr -d '"' | sort -u > /tmp/menu.txt
comm -23 /tmp/screens.txt /tmp/menu.txt
```

ห้ามใช้ `grep -ohE '"/[a-z0-9/-]+"'` กวาดทั้งไฟล์ เพราะจะติด backend `basePath`/`listPath` และ `/api/*` ปนมาเป็น 63 บรรทัด ไม่ตรงกับข้อสรุปด้านล่าง

ผลตรวจ 2026-09-08 หลังต่อสาย marketplace (รันซ้ำ 2026-09-09 ได้ 17 บรรทัด): เหลือ `/currency`, `/datamodelgraph`, `/shortcuts` ที่อยู่นอกเมนูโดยตั้งใจ (workspace wizard / เครื่องมือ dev / แท็บทางลัดเต็มจอ) และ route ตั้งค่าองค์กรที่ห้ามอยู่ในเมนูหลักตามเทสต์ `has no settings section in the main menu` — ไม่มีจอกำพร้าที่ผิดพลาดเหลืออยู่
