# ความครบของเมนู BC เทียบ FlowAccount + PEAK
> ตรวจล่าสุด: 2026-09-08 — เทียบเมนูจริงใน `frontend/src/lib/menu-data.ts` กับฟีเจอร์ที่อ่านจากหน้าทางการของ FlowAccount (flowaccount.com — help center / pricing / functions) และ PEAK (peakaccount.com — peak-manual / หน้าผลิตภัณฑ์) เมื่อ 2026-09-08 · ผลสำรวจ 411 รายการ, จับคู่ว่าครอบคลุมแล้ว 230 คู่, ช่องว่างที่ยืนยันแบบ adversarial 20 ข้อ

## สรุปผล

หลังเพิ่มเมนูรอบนี้ **BC ครอบคลุมงานหลักของทั้ง FlowAccount และ PEAK แล้วในระดับ "มีเมนู"** — 200 รายการเมนู (เดิม 185) และมีสิ่งที่ทั้งสองเจ้าไม่มีอยู่แล้วหลายกลุ่ม (POS/ร้านอาหาร, BOQ, marketplace, ชั้นต้นทุน FIFO, สินค้าชุด/BOM, เลขเครื่อง/serial, ทางลัดผู้ใช้)

**ข้อยกเว้นที่ตั้งใจไม่ทำ: ระบบเงินเดือน (payroll)** — ลุงจืดตัดสินใจ 2026-09-08 ว่า **ไม่เอาระบบเงินเดือน** ดังนั้น BC จะไม่มีโมดูลเทียบ FlowPayroll / PEAK Payroll และไม่มีแบบยื่นที่เกิดจากเงินเดือน (ภ.ง.ด.1, ไฟล์นำส่งประกันสังคม) — ถือเป็นความต่างที่ยอมรับแล้ว ไม่ใช่ช่องว่างที่ต้องปิด **ห้าม AI ตัวใดเพิ่มเมนูเงินเดือนกลับเข้ามาเองอีก**

**"มีเมนู" ≠ "ทำงานได้"** — เมนูส่วนใหญ่ของ BC ยังชี้ไป route ที่ยังไม่มีจอจริงใน Next (แสดงการ์ด "Flutter route เดิม" ที่ `frontend/src/app/menu/main-menu-screen.tsx:2786-2800`) เอกสารนี้พูดถึงความครบของ **แผนผังเมนู** เท่านั้น

## เมนูที่เพิ่ม 2026-09-08 (15 รายการ)

| หมวด | รายการที่เพิ่ม | ที่มา | ต้องให้ลุงจืดกำหนดกฎ |
|---|---|---|---|
| งานประจำ › ซื้อ | ทะเบียนใบกำกับภาษีซื้อ (`/transaction/purchasetaxinvoice`) | PEAK ทะเบียนใบกำกับภาษีซื้อ (รอรับ/รับแล้ว/เลื่อนงวด) | ไม่ (แต่กฎ 6 เดือนของงวดเคลมต้องยึดประกาศสรรพากร) |
| งานประจำ › รับ/จ่ายเงิน | ใบเสร็จรับเงินรายได้อื่น, เงินทดรองจ่ายพนักงาน, ไฟล์โอนเงินจ่ายผ่านธนาคาร | FlowAccount + PEAK | ใช่ (รูปแบบไฟล์ธนาคาร, ผังบัญชีรายได้อื่น, บัญชีสำรองจ่ายรายคน) |

| รายงาน › การเงิน | ภาพรวมธุรกิจ, วิเคราะห์ธุรกิจสำหรับผู้บริหาร, ส่งออกงบการเงิน XBRL (ยื่น DBD) | FlowAccount Dashboard, PEAK Board, PEAK XBRL | ใช่ (ชุด KPI/อัตราส่วน, taxonomy DBD) |
| รายงาน › ขาย | ยอดขายตามลูกค้า, ยอดขายตามช่องทางขาย | ทั้งสองเจ้า | ไม่ |
| รายงาน › จัดซื้อ | รายงานซื้อ, รายงานซื้อตามสินค้า | ทั้งสองเจ้า | ไม่ |
| ข้อมูลหลัก › นำเข้า/ส่งออก | นำเข้ารายชื่อคู่ค้า, นำเข้าเอกสารจากไฟล์ | ทั้งสองเจ้า | ใช่สำหรับ "นำเข้าเอกสาร" (จะรองรับเทมเพลตของแพลตฟอร์มไหน) |

ก่อนหน้านี้ commit `20b9fd3d` (2026-09-07) เพิ่มเมนูบัญชี/ภาษี/สินทรัพย์/ธนาคารจากการเทียบรอบแรกไว้แล้ว 33 รายการ และเตรียม language key `payroll`, `employee_payroll`, `payroll_run`, `payroll_slip` ค้างไว้ — key เหล่านั้นถูกลบทิ้งแล้วตามการตัดสินใจไม่ทำเงินเดือน

## ที่ตรวจแล้วว่า BC มีอยู่แล้ว (ตัวอย่างที่คนมักคิดว่าขาด)

| ของ FlowAccount / PEAK | ของ BC ที่ครอบคลุม |
|---|---|
| ทะเบียนพนักงาน | จอ `/employee` ใน workspace wizard (`frontend/src/lib/system-setting-screens.ts`) ไม่ได้อยู่ใน MENU_SECTIONS โดยตั้งใจ |
| ใบกำกับภาษีอย่างย่อ | `tax-invoice` + จอ POS (`pos-setting`, `cash-drawer`) |
| กำไรขาดทุนแยกแผนก/โครงการ | `project-pnl`, `project-summary-report`, `project-department-tags` |
| ทะเบียนสินทรัพย์ + ค่าเสื่อม | กลุ่ม `fixed-assets` (`asset-registry`, `asset-depreciation`, `asset-disposal`) |
| รายงานเคลื่อนไหวเงินสด/ธนาคาร | `rv-journal`, `pv-journal`, `bank-statement`, `bank-reconcile`, `general-ledger` |
| เชื่อมต่อ LINE | จอ `/line-oa` (เปิดเป็นแท็บได้จาก `main-menu-screen.tsx`) ยังไม่อยู่ในเมนู |

## ช่องว่างที่ยังไม่ตัดสิน (ยังไม่เพิ่มเมนู — ห้ามเดา ต้องถามลุงจืด)

1. **ล็อตสินค้า / วันหมดอายุ (lot & expiry)** — BC มี `product-serial-registry` (เลขเครื่อง) แต่ไม่มีล็อต/วันหมดอายุ; ตัวตรวจสอบข้อนี้รันไม่จบ (ชน usage limit) จึงยังไม่ยืนยันว่าคู่แข่งมีจริงแค่ไหน
2. **รายงานสรุปส่งอีเมลอัตโนมัติตามรอบ** — ยังไม่ยืนยัน
3. **ส่งออก/สำรองข้อมูลกิจการทั้งชุด** — ยังไม่ยืนยัน; เกี่ยวกับ backup policy ที่ยังไม่มีคำตอบ (`docs/runbooks/RECOVERY-READINESS.md`)
