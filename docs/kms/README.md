## กติกา

- **โค้ด = ความจริง, docs ตามโค้ด** — ทุกข้อเท็จจริงในนี้ต้องอ้าง `path:line` ของโค้ดจริงและระบุวันที่ตรวจ; ถ้าโค้ดเปลี่ยน แก้ docs ใน commit เดียวกัน
- หัวข้อละ 1 ไฟล์ Markdown ชื่อ kebab-case; ขึ้นต้นด้วยบรรทัด `> ตรวจล่าสุด: YYYY-MM-DD (commit …)`; ไม่เก็บ secret/PII
- ห้ามเดา: ถ้ายังไม่ได้ตรวจ ให้เขียนว่า "ยังไม่ตรวจ" แทนการแต่ง
- เพิ่มไฟล์ใหม่แล้วต้องเพิ่มบรรทัดในดัชนีด้านล่าง (บรรทัดละ 1 ไฟล์ + hook สั้น ๆ)
- skill ส่วนตัว (วิธีทำงานเฉพาะเรื่อง) อยู่ที่ `docs/skills/` ไม่ใช่ที่นี่; handoff ระหว่าง session อยู่ที่ root `HANDOFF-*.md` (อ่านตัวล่าสุดก่อนเสมอ)
