# ป้ายเมนูและชื่อฟิลด์ใช้ถ้อยคำเดียวกับระบบเดิม (Champ)

## ที่มา

ลุงจืดสั่ง 2026-09-16: *"พยายามเปลี่ยนชื่อเมนู และชื่อ field ให้เหมือน D:\project-champ เพราะลูกค้าเวลา upgrade จะได้ไม่สับสน"*

ก่อนหน้านี้ผังเมนูถูกจัดตาม Champ แล้ว ([2026-09-11](2026-09-11-champ-upgrade-menu-workflows.md)) แต่ **ถ้อยคำ** ยังเป็นภาษาที่เราตั้งเอง (สั้นและทันสมัย เช่น "ใบสั่งซื้อ", "คืนซื้อ") ผู้ใช้เดิมที่จำชื่อจากโปรแกรมเก่า ("บันทึกใบสั่งซื้อสินค้า", "บันทึกส่งคืนสินค้า") จึงหาเมนูไม่เจอ

## การตัดสินใจ

1. **ป้ายที่ผู้ใช้เห็น = ถ้อยคำของระบบเดิม** เมื่อเมนู/จอนั้นตรงกับงานเดียวกันใน `menuconfig.xml` — รวมคำนำหน้า "บันทึก…/กำหนด…/รายละเอียด…/รายงาน…" ตามต้นฉบับ
2. **ชื่อเดิมของเราไม่หาย แต่ย้ายไปเป็นคำค้น** (`CHAMP_SEARCH_ALIASES` ใน `frontend/src/lib/menu-data.ts`) ผู้ใช้ใหม่ที่พิมพ์ "คืนซื้อ" ยังเจอ "บันทึกส่งคืนสินค้า"
3. **ไม่เปลี่ยนเมื่อถ้อยคำของเราชัดกว่าและไม่ทำให้ผู้ใช้เดิมหลง** เช่น "คำนวณค่าเสื่อมราคา" (เดิม "ประมวลผลสินทรัพย์"), "คำนวณยอดคงเหลือบิลเจ้าหนี้ใหม่" (เดิม "คำนวณยอดคงเหลือของบิลใหม่" ซึ่งซ้ำกันทั้ง AP และ AR) — กรณีเหล่านี้เก็บคำเดิมเป็น alias อย่างเดียว
4. **id / route / language key ห้ามเปลี่ยน** เพราะเป็นรหัสสิทธิ์การใช้งานและเส้นทางหน้าจอ
5. **ชื่อฟิลด์ยึดคำเดียวกันเมื่อเป็นฟิลด์เดียวกัน** เช่น คู่ค้าฝั่งซื้อเรียก "เจ้าหนี้" (ไม่ใช่ "ผู้จำหน่าย"), "เลขประจำตัวผู้เสียภาษี" (ไม่ใช่ "เลขผู้เสียภาษี")
6. **หัวจอต้องตรงกับชื่อเมนูที่กดเข้ามา** — `erp-transaction.ts` ใช้ป้ายเดียวกับ `menu-data.ts` ทุกจอที่เปลี่ยนชื่อ

## ขอบเขตที่ทำจริงรอบนี้

- เมนู 103 รายการเปลี่ยนป้ายไทย (จาก 225 รายการ; ที่เหลือคือของที่ตรงอยู่แล้วหรือเป็นฟีเจอร์ใหม่ที่ Champ ไม่มี เช่น marketplace, LINE OA, e-Tax, Dashboard)
- `backend/assets/language/languages.tsv` แก้คอลัมน์ `th` ให้ตรงกับป้ายใหม่ 105 แถว + เพิ่มคีย์ `general_ledger` (13 ภาษา) และย้ายเมนูสมุดบัญชีจากคีย์รวม `bank_book` ไปคีย์ของตัวเอง `book_bank`
- หัวจอธุรกรรม 60 จอใน `frontend/src/lib/erp-transaction.ts` ตามชื่อเมนูใหม่ + ป้ายคู่ค้า 20 จุด "ผู้จำหน่าย" → "เจ้าหนี้"
- จอตั้งค่า 5 จอ (`system-setting-screens.ts`) ใช้ชื่อเดียวกับเมนู
- รายงานคอลัมน์ "ผู้จำหน่าย" ใน `erp-reports.ts` 3 จุด

## กับดักที่เจอ (ห้ามพลาดซ้ำ)

- **คีย์ภาษาบางตัวใช้ร่วมกันทั้งระบบ** (`ledger`, `report`, `transaction`, `finance`, `approval`, `bank_book`) — สคริปต์ที่ไล่แก้คอลัมน์ `th` ตามชื่อเมนูเคยไปทับคีย์กลางเหล่านี้ ต้องตรวจ `git diff` ของ tsv ทุกแถวก่อน commit และคืนค่าแถวกลางเสมอ
- `menuText()` คืน `label.th` ตรง ๆ สำหรับภาษาไทย แต่เทสต์ `menu-data.test.ts` บังคับว่า `languages.tsv` คอลัมน์ `th` ต้องตรงกับ `label.th` ทุกเมนู — แก้ที่เดียวไม่พอ
- `system-setting-screens.ts` เป็น CRLF ทั้งไฟล์ การแก้ทีละบรรทัดด้วย Node ต้องคง `\r` ไว้ ไม่งั้นได้ diff ปลอมทั้งไฟล์

## หลักฐาน

- `npm run verify` ผ่าน (codemap + frontend lint/typecheck/test 566 เทสต์)
- ทดสอบบนจอจริง (demo holding): ค้นคำเก่า "คืนซื้อ" แล้วเจอเมนูใหม่ "บันทึกส่งคืนสินค้า"; เปิดจอใบสั่งซื้อแล้วหัวจอขึ้น "บันทึกใบสั่งซื้อสินค้า" และคอลัมน์คู่ค้าขึ้น "เจ้าหนี้"

## สิ่งที่ยังไม่ได้ทำ

- ป้ายฟิลด์ในจอย่อยอีกมาก (`system-setting-screens.ts` มีคำไทยของเราเอง 596 คำ ตรงกับ Champ แค่ 64 คำ) — ต้องไล่ทีละจอเทียบ dialog ใน `BC5Account.rc` (Windows-874, ป้ายอยู่ในรูป `KEY$ข้อความไทย`)
- ชื่อรายงานที่ Champ ยังไม่มีในระบบเรา ดูช่องว่างที่ [19-menu-coverage-market-standard.md](../19-menu-coverage-market-standard.md)
