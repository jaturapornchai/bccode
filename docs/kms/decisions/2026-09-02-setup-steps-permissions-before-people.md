# ตั้งค่าระบบ: สิทธิ์การใช้งาน มาก่อน คนในองค์กร

## Context
wizard 4 ขั้นเดิม: ธุรกิจ → คน → สิทธิ์ → ตรวจสอบ. หลังเพิ่ม "สิทธิ์การใช้งานเพิ่มเติม" (เลือกได้หลายชุด) ในจอบัญชีเข้าระบบ ผู้ใช้ต้องข้ามไปขั้นสิทธิ์เพื่อสร้างชุดแล้วย้อนกลับ

## Decision
สลับเป็น ธุรกิจ → สิทธิ์การใช้งาน (ข้ามได้) → คนในองค์กร → ตรวจสอบ. ใช้คำว่า "สิทธิ์การใช้งาน" สม่ำเสมอ. (ลุงจืดยืนยัน; ความเห็น Kimi K3 ตรงกัน — เป็นครั้งแรกที่ใช้ advisor นอกค่ายหลังยกเลิกกฏ 2026-09-02)

## Consequences
- + wizard เดินหน้าทางเดียว, ตรง mental model "กำหนดหน้าที่ก่อน แล้วจับคนลง"
- − คนที่คิดเป็น "คน" ก่อนอาจข้ามขั้นสิทธิ์แล้วไปติดที่ขั้นคน → ระยะถัดไป: ปุ่มสร้างชุดใหม่ (modal) ในจอบัญชี
