# มาตรฐานการแยกโหมดแสดงข้อมูลและโหมดแก้ไขใน CRUD (CRUD List-Detail View Mode vs Edit Mode Standard)

- **วันที่:** 2026-09-13
- **ผู้มีส่วนร่วม:** ลุงจืด, AI Pair Programming
- **สถานะ:** Approved & Implemented

---

## 1. บริบทและปัญหา (Context & Problem)

ในระบบบันทึกและจัดการข้อมูลหลัก (Master CRUD) และสมุดรายวัน (Journals) ของระบบบัญชีแยกประเภท เดิมทีเมื่อผู้ใช้คลิกเลือกแถวใดๆ ในตารางรายการ ระบบจะโหลดข้อมูลเข้าไปในฟอร์มที่เปิดให้พิมพ์แก้ไขได้ทันที และแสดงปุ่ม **"บันทึกข้อมูล"** หรือ **"บันทึกฉบับร่าง"** ค้างไว้ตลอดเวลา

พฤติกรรมดังกล่าวทำให้เกิดความเสี่ยงสูงต่อการทำงานของผู้ใช้งานบัญชี (อายุ 40+ ปี) ซึ่งส่วนใหญ่คลิกเลือกแถวเพื่อ **เปิดดูข้อมูล (Inspection/Review)** เช่น ตรวจสอบรายละเอียดบัญชี ยอดงบประมาณ วันที่ หรืองวดบัญชี แต่กลับพบว่าช่องกรอกเปิดให้พิมพ์ได้และมีปุ่มบันทึกพร้อมกด อาจเกิดการเผลอพิมพ์แก้ไขหรือกดบันทึกทับข้อมูลจริงโดยไม่ได้ตั้งใจ

ลุงจืดจึงได้ตั้งกฎใหม่:
> *"CRUD เมื่อกดบรรทัดนั้นๆ ให้ถือเป็นการแสดงข้อมูล ถ้าต้องการแก้ไข ต้องกดปุ่ม แก้ไข การแสดงข้อมูล จะกด Save หรือ Update ไม่ได้ ตรวจให้หมด"*

---

## 2. การตัดสินใจ (Decision)

แยกพฤติกรรมของตารางรายการและพาเนลรายละเอียด (List-Detail Workbench) ออกเป็น 2 โหมดอย่างเด็ดขาด:

### 1) โหมดแสดงข้อมูล (View Mode / Read-only):
- **ทริกเกอร์:** การคลิกแถว (Row Click) ในตารางรายการทุกตาราง ให้เปิดใน **โหมดแสดงข้อมูล** เสมอ
- **ข้อกำหนดความปลอดภัย (Strict Constraints):**
  - ฟิลด์กรอกข้อมูลทั้งหมดต้องเป็น Read-only หรือครอบด้วย `<fieldset disabled className="opacity-95">` ป้องกันการแก้ไข
  - **ห้ามมีปุ่ม "บันทึก" (Save) หรือ "ปรับปรุง" (Update) หรือ `<button type="submit">` โผล่มาให้กดเด็ดขาด**
  - ส่วนหัว (Header) แสดงชื่อรายการ พร้อม Badge `โหมดแสดงข้อมูล`
  - มีแบนเนอร์แจ้งสถานะ: `โหมดแสดงข้อมูล (Read-only) — หากต้องการแก้ไข ให้กดปุ่ม "แก้ไข"`
  - มีปุ่มเด่น **"แก้ไข" / "แก้ไขข้อมูล"** (`Pencil` icon) เพื่อสลับเข้าสู่โหมดแก้ไขอย่างชัดแจ้ง
  - มีปุ่ม "ปิด" (`X` icon) เพื่อปิดพาเนล
  - ค่า `dirty` เป็น `false` เสมอ ทำให้ผู้ใช้สามารถคลิกดูรายการอื่นๆ ในตารางได้อย่างรวดเร็วโดยไม่มี popup ขวาง

### 2) โหมดแก้ไข (Edit Mode):
- **ทริกเกอร์:** เข้าสู่โหมดแก้ไขได้เมื่อ:
  - กดปุ่ม "แก้ไข" (`Pencil` icon) ในคอลัมน์ "จัดการ" ของแถวนั้นในตาราง
  - กดปุ่ม "แก้ไข" / "แก้ไขข้อมูล" ในหน้าต่าง View Mode
  - กดปุ่ม "+ เพิ่มรายการ" เพื่อสร้างรายการใหม่
- **ฟังก์ชันการทำงาน:**
  - ฟิลด์กรอกข้อมูลเปิดใช้งานปกติ
  - แสดงปุ่ม **"บันทึกข้อมูล" / "บันทึกฉบับร่าง"** (`Save` icon) และปุ่ม **"ยกเลิก"**
  - ปุ่ม "ยกเลิก" จะคืนค่าข้อมูลกลับเป็นค่าเดิม (`original`) และสลับกลับไปที่โหมดแสดงข้อมูล (View Mode) ทันที
  - มี Dirty Guard เตือนเมื่อมีข้อมูลค้างบันทึกแล้วพยายามปิดหรือเปลี่ยนหน้า
  - **สีพื้นหลังแถวในตารางด้านซ้าย (Datalist Row Background):** แถวของรายการที่กำลังถูกแก้ไข จะเปลี่ยนสีพื้นหลังเป็นโทนสีส้ม/อำพัน (`bg-amber-100/70 dark:bg-amber-950/40`) พร้อมกรอบ `ring-amber-500/50` และตัวหนังสือสีอำพัน เพื่อให้ผู้ใช้มองเห็นได้ทันทีว่าฟอร์มด้านขวากำลังแก้ไขแถวใดอยู่ ต่างจากโหมดแสดงข้อมูล (View Mode) ที่ใช้สีประจำธีมระบบ (`bg-primary/10`)

## 3. หน้าจอและคอมโพเนนต์ที่ปรับปรุง (Affected Screens)

1. **`frontend/src/app/gl/gl-masters.tsx` (`GLMasters`)**:
   - รองรับทั้ง 8 แหล่งข้อมูลหลัก: `accounts`, `fiscal-years`, `budgets`, `periods`, `account-groups`, `mappings`, `product-account-groups`, `forecast`
   - แถวตารางมีคอลัมน์ "จัดการ" พร้อมปุ่มแก้ไข (Pencil) และลบ (Trash2)
   - แยก View Mode (มีปุ่ม "แก้ไขข้อมูล", ปิด, ล็อกงวด, ลบ) กับ Edit Mode (มีปุ่ม "บันทึกข้อมูล", "ยกเลิก")
2. **`frontend/src/app/gl/gl-journals.tsx` (`GLJournals`)**:
   - รองรับทั้งสมุดรายวันทั่วไป (JV, RV, PV, SV, BV) และยอดยกมา (Opening Balance)
   - แถวตารางเพิ่มคอลัมน์ "จัดการ" พร้อมปุ่มแก้ไข (Pencil) และลบ (Trash2) สำหรับฉบับร่าง
   - แยก View Mode (มีปุ่ม "แก้ไขฉบับร่าง", "ผ่านรายการบัญชี", "ลบฉบับร่าง", "สร้างรายการกลับบัญชี") กับ Edit Mode (มีปุ่ม "บันทึกฉบับร่าง", "ยกเลิก")
3. **`frontend/src/app/gl/gl-statement-designer.tsx` (`GLStatementDesigner`)**:
   - แถวตารางเพิ่มคอลัมน์ "จัดการ" พร้อมปุ่มแก้ไข (Pencil)
   - เมื่อคลิกแถวในตาราง จะเปิดในโหมด Preview (พรีวิวและพิมพ์งบจริง) เสมอ
   - ในโหมด Preview ไม่มีปุ่ม Save แต่มีปุ่ม "แก้ไขผังงบ" ที่จะสลับเข้าสู่โหมดออกแบบ (Design Mode)
   - ปุ่ม "บันทึกแม่แบบ" (Save) จะปรากฏเฉพาะเมื่ออยู่ในโหมดออกแบบ (Design Mode) เท่านั้น
