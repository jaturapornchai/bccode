# หมายเหตุประกอบงบการเงิน + ซ่อนรายการที่ไม่มียอด (ข้อ 7) + ตรวจเงินสดปลายงวดกับบัญชี + ชื่อ "งบฐานะการเงิน"

ต่อจาก ADR `2026-09-26-gl-equity-statement-amount-basis.md` — ลุงจืดเลือกทำทั้ง 4 ข้อ (2026-09-26) และเลือกชื่อเมนู "งบฐานะการเงิน"

## Context

- **หมายเหตุประกอบงบการเงิน** เป็นส่วนหนึ่งของงบการเงินบริษัทจำกัด: ประกาศกรมพัฒนาธุรกิจการค้า เรื่อง กำหนดรายการย่อที่ต้องมีในงบการเงิน พ.ศ. 2566 **แบบ 2 ข้อ 5** (หน้า 2-30..2-31; ทะเบียน `DBD-FS-2566-N5` ใน `docs/kms/21-thai-tax-form-references.md`) — 5.1 ข้อมูลทั่วไป, 5.2 เกณฑ์การจัดทำ (5.2.1 ต้องระบุว่าจัดทำตาม TFRS for NPAEs หรือ TFRS for PAEs), 5.3 นโยบายการบัญชี, 5.4 ประมาณการทางบัญชี, 5.5 ข้อผิดพลาดในงวดก่อน, 5.6 ข้อมูลเพิ่มเติมอื่น ๆ; ระบบไม่มีที่เก็บ ส่วน Champ ไม่มี (มีแค่คอลัมน์หมายเหตุในตัวออกแบบงบ)
- **ข้อ 7 ของประกาศ**: รายการที่กิจการไม่มีไม่ต้องแสดง — แม่แบบแบบ 2 มีบรรทัดครบทุกรายการ กิจการเล็กจึงได้งบที่มีแต่บรรทัด 0
- **งบกระแสเงินสด**: ยอดเงินสดปลายงวดตามงบมาจากสูตรที่ผู้ใช้ตั้ง ถ้าเลือกบัญชีไม่ครบ ตัวเลขจะไม่ตรงกับบัญชีเงินสดโดยไม่มีใครรู้ (UAT r20260926-4: ตามงบ 1,888,400 vs ตามบัญชี 1,793,120)
- **ชื่องบ**: เมนูเดิม "งบดุล" (Champ); แบบ 2 ใช้หัว "งบฐานะการเงิน", TFRS for NPAEs ใช้ "งบแสดงฐานะการเงิน"

## Decision

1. **หมายเหตุ = ข้อมูลหลักชนิด `statement-notes`** (`gl_records`, `statement_notes.go`) ปีละรายการต่อบริษัท `code` = รหัสปีบัญชีที่มีอยู่จริง, `notes[] {id, noteno, title, body}`
   - ตรวจก่อนบันทึก: เลขที่ต้องมีและไม่ซ้ำ ≤ 10 ตัวอักษร, หัวข้อต้องมี ≤ 200, เนื้อหา ≤ 20,000, ไม่เกิน 100 ข้อ (นับ rune); id ว่าง/ซ้ำ/ยาวเกิน 64 สร้างใหม่; ข้อมูลหลักชนิดอื่นไม่เก็บ `notes`
   - ลบปีบัญชีที่ยังมีหมายเหตุไม่ได้ (`postgres_guards.go`) — กันหมายเหตุค้างแล้วกลับมาเมื่อสร้างปีรหัสเดิม
   - สิทธิ์ผูกจอ `financial-statement-designer`; BFF รับผ่าน `GL_RESOURCES`
   - งบทุกชนิดเตือนเมื่อบรรทัดที่ **พิมพ์จริง** (หลังซ่อนยอดศูนย์) อ้างเลขหมายเหตุที่ยังไม่มีในปีที่ออกงบ; อ้างหลายข้อแยกด้วย `,` `;` ช่องว่าง (รวม NBSP จาก Word/Excel) หรือ "และ"; "5.1.2" ถือว่ามีถ้ามีข้อ 5.1.2, 5.1 หรือ 5; เทียบเลขที่แบบตัดจุดท้ายและเลขไทยเป็นอารบิก ("๕." = "5" ทั้งตอนตรวจซ้ำและตอนเทียบ; เก็บเลขไทยตามที่พิมพ์ ตัดเฉพาะจุดท้าย); ไม่ติ๊ก "แสดงคอลัมน์หมายเหตุประกอบงบ" = ไม่ตรวจ
   - จอ: ปุ่มสลับโหมด "รูปแบบงบการเงิน | หมายเหตุประกอบงบการเงิน" ในจอออกแบบงบ (ไม่เพิ่มเมนู), ปุ่ม "เริ่มจากหัวข้อตามแบบ 2" (6 หัวข้อ ข้อ 2 เติมประโยค TFRS for NPAEs ให้แก้ได้), ยืนยันก่อนลบข้อที่มีเนื้อหาและก่อนลบทั้งปี, dirty guard, พิมพ์ A4 แนวตั้ง (`GLNotesPrint`); บันทึก/ลบชนกับฉบับที่บันทึกไว้ (`stale_version`/`duplicate_code`/`not_found`) → ปุ่ม "โหลดหมายเหตุล่าสุด" (ยืนยันละทิ้งก่อน) และ backend บอกว่าปีนี้มีหมายเหตุแล้ว ไม่ใช่ "ใช้รหัสอื่น"
2. **ซ่อนรายการที่ไม่มียอด** `globalstyle.hidezerorows` (`statements_hidezero.go`) กรองที่ backend หลังคำนวณ ทีละชุดปี
   - แถวยอดเงินซ่อนเมื่อทุกคอลัมน์เป็นศูนย์ตามทศนิยมที่แสดงและไม่ได้ติ๊ก "แสดงศูนย์" — ยกเว้นแถวสูตร/ยอดรวมที่ยังมีแถวที่มันอ้างถึงแสดงอยู่ (วนจนนิ่ง)
   - หัวข้อซ่อนเมื่อทุกแถวยอดเงินในหมวดถูกซ่อน; บรรทัดว่าง/เส้นคั่นซ้ำหรือค้างหัว-ท้ายถูกตัด
   - งบส่วนของผู้ถือหุ้นตัดคอลัมน์องค์ประกอบที่เป็นศูนย์ทุกแถวทุกปี (คอลัมน์รวมคงไว้)
   - แม่แบบเริ่มต้นทั้ง 5 ตั้ง `hidezerorows` และติ๊ก "แสดงศูนย์" ที่บรรทัดยอดรวมสุดท้าย (งวดที่ไม่มีรายการยังได้งบที่มีบรรทัดรวม); BS-DBD "รวมหนี้สิน" (540) ย่อหน้า 1 ให้ส่วนของหัวข้อ "หนี้สินและส่วนของผู้ถือหุ้น" ครอบถึงส่วนของผู้ถือหุ้น (กิจการไม่มีหนี้สินยังเห็นหัวข้อ) — `general-ledger.test.ts` ตรวจทุกแม่แบบว่าไม่มีหัวข้อที่ส่วนจบที่ยอดรวมย่อยแล้วมีแถวลึกกว่าตามมา
3. **ตรวจเงินสดปลายงวดกับบัญชี** (`statements_cashcheck.go`) เฉพาะงบ `cash_flow`: บรรทัดสูตรที่อ่านแถว `amountbasis: opening` ร่วมกับแถวอื่น = เงินสดปลายงวด → เทียบกับยอดตามบัญชีที่คำนวณด้วย **สูตรของบรรทัดนั้นเอง** โดยให้แถวต้นงวดที่อ้างถึงเป็น **ยอดคงเหลือปลายงวด** ของบัญชีในแถวนั้น และแถวบัญชีอื่นเป็น 0 (คงเครื่องหมาย/สัมประสิทธิ์ของสูตร เช่น เงินสด − เงินเบิกเกินบัญชี); สูตรที่อ่านแต่แถวต้นงวด = ยอดต้นงวดรวม ไม่ตรวจ; สูตรที่อ่านแถว `closing` ด้วย = การเปลี่ยนแปลงยอดคงเหลือ ไม่ตรวจ; สูตรที่อ่านแต่แถว `closing` = ยอดปลายงวดรวม นับเหมือนแถว `closing`; ผลอยู่ใน `report.checks[]` (ปีนี้ + ปีก่อน) และไม่ตรงกัน = คำเตือน; แถวต้นงวดยังไม่เลือกบัญชี = เตือนให้เลือก (ไม่ขึ้น "ไม่ตรงกัน" กับยอด 0); ตรวจจากค่าเต็มก่อนซ่อนยอดศูนย์; จอแสดงกล่อง "ตรวจยอดกับบัญชี" และคำเตือนเป็นกล่องสีเตือน นอกตารางพิมพ์
4. **ชื่อ "งบฐานะการเงิน"** (ลุงจืดเลือก ตามแบบ 2): เมนู `/report/balancesheet`, ป้ายประเภทงบ "งบฐานะการเงิน (งบดุล)", ชื่อแม่แบบ `BS-DBD`; "งบดุล" และ "งบแสดงฐานะการเงิน" ยังค้นหาเจอ (`CHAMP_SEARCH_ALIASES`) — route/key ไม่เปลี่ยน
5. `globalstyle.shownotecolumn` เป็น `*bool` — ค่า false ที่ผู้ใช้เลือกเก็บได้จริง (เดิม `omitempty` ทิ้ง false จอจึงกลับมาแสดงคอลัมน์หมายเหตุ)

## Alternatives considered

- **หมายเหตุเป็นฟิลด์ข้อความในรูปแบบงบ** — หมายเหตุเป็นของปีบัญชี ไม่ใช่ของรูปแบบ; หลายรูปแบบต้องอ้างชุดเดียวกัน
- **สร้างเนื้อหาหมายเหตุอัตโนมัติ (นโยบายบัญชี, รายละเอียดบัญชีย่อย)** — ไม่ทำ: เนื้อหาเป็นการตัดสินใจของผู้ทำบัญชี; ระบบให้แค่หัวข้อตามแบบ 2
- **ตรวจเงินสดด้วยคุณสมบัติ `iscash` ของผังบัญชี** — จอผังบัญชีไม่มีช่องนี้ (มีแค่ข้อมูลตั้งต้น) ถ้าใช้จะปิดการตรวจเงียบ ๆ ในผังที่ผู้ใช้สร้างเอง → ใช้บัญชีที่ผู้ใช้เลือกในแถวต้นงวดแทน
- **ซ่อนยอดศูนย์ที่หน้าจอ** — ผิดกฎ backend-first และ API/MCP จะได้ผลไม่ตรงกับหน้าพิมพ์

## Consequences

- ✅ บริษัทจำกัดมีหมายเหตุตามแบบ 2 ในจอเดิม, งบไม่รกด้วยบรรทัด 0, งบกระแสเงินสดเตือนเมื่อปลายงวดไม่ตรงบัญชี
- ⚠️ ตรวจเงินสดได้เฉพาะสูตรที่อ้างแถวต้นงวดโดยตรง — สูตรที่อ้างแถวปลายงวดอีกทอด (`R190 = R180`) ไม่ถูกตรวจซ้ำ; บัญชีเงินสดที่ผู้ใช้ไม่ได้เลือกเลยในแถวต้นงวดจะไม่ถูกนับทั้งสองฝั่ง
- ⚠️ ขนาดคำขอสูงสุด 2 MB — หมายเหตุเต็มเพดานทุกข้อส่งไม่ผ่าน (ใช้งานจริงไม่ถึง)
- ⚠️ พิมพ์งบกับหมายเหตุยังเป็นสองครั้ง (สองปุ่ม)
