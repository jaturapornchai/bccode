# สถาปัตยกรรมและระบบค้นหาผังบัญชีแบบเต็มจอ (Full-Screen Chart of Accounts Search Dialog)

## บริบทและโจทย์ความต้องการ (Context & Requirement)

ลุงจืดได้สั่งการ:
> "ออกแบบระบบค้นหาผังบัญชี ให้เต็มจอด้วย ให้สวยๆ ใช้ง่่าย"
> พร้อมแนบภาพของ native HTML `<select>` dropdown ที่มีรายการ `เลือกบัญชี` และรายการผังบัญชีในหน้าต่างป๊อปอัปขนาดเล็ก แคบ และไม่มีช่องค้นหา

ในการทำงานบัญชีจริงของโปรแกรม ERP ผังบัญชีของกิจการมักมีหลายสิบถึงหลายร้อยรายการ การค้นหาผ่าน dropdown เมนูของเบราว์เซอร์ไม่ตอบโจทย์ผู้ใช้งานวัย 40+ เพราะไม่สามารถพิมพ์ค้นหาคำภาษาไทยได้สะดวก ไม่เห็นหมวดหมู่ ไม่เห็นระดับชั้นบัญชี (Level) และไม่เห็นด้านบัญชีเดบิต/เครดิต

## สถาปัตยกรรมการออกแบบและการแก้ไข (Architectural Implementation)

### 1. คอมโพเนนต์ `AccountSearchDialog` (`frontend/src/app/gl/account-search-dialog.tsx`)
- **มุมมองแบบเต็มจอ / จอใหญ่ (Full-Screen & Large Viewport)**:
  - รองรับโหมดเต็มจอ (`fixed inset-0 w-full h-full`) และโหมดหน้าต่างกว้างพิเศษ (`max-w-6xl h-[92vh]`)
  - มีปุ่มสลับขยาย/ย่อหน้าต่าง (Maximize / Restore) ที่มุมขวาบน
  - Backdrop Blur นุ่มนวล คอนทราสต์สูงตามเกณฑ์ WCAG AA
- **ช่องค้นหาอัจฉริยะ (Hero Search Input)**:
  - ขนาดใหญ่ ตัวหนังสือ `text-lg` พร้อม Auto-focus ทันทีเมื่อเปิด
  - ค้นหาได้ทั้งรหัสบัญชี (เช่น `1101`), ชื่อบัญชีภาษาไทย (เช่น `เงินสด`), ชื่อบัญชีภาษาอังกฤษ, และหมวดบัญชี
  - มีปุ่มล้างคำค้นหา (`✕`)
- **แท็บหมวดบัญชี 5 หมวดหลัก (Category Pills)**:
  - ทั้งหมด, 1. สินทรัพย์, 2. หนี้สิน, 3. ส่วนของเจ้าของ, 4. รายได้, 5. ค่าใช้จ่าย พร้อมตัวเลขนับจำนวน (Counter Badge)
  - ตัวกรองเพิ่มเติม: "เฉพาะบัญชีลงรายการ" และตัวกรอง "ระดับบัญชี (Level 1, 2, 3+)"
- **ตารางแสดงผลผังบัญชี (High Readability Grid)**:
  - แสดงรหัสบัญชีใน font-mono สี primary ตัวหนา
  - แสดงชื่อบัญชีพร้อมการเยื้องตามระดับชั้น (Level 1–12) ด้วยสัญลักษณ์ `└─ `
  - Badge สีประจำหมวดบัญชี (Asset = น้ำเงิน, Liability = ส้ม/อำพัน, Equity = ม่วง, Income = เขียว, Expense = แดง/ชมพู)
  - แสดงด้านปกติ (เดบิต/เครดิต) และสถานะสิทธิ์ลงรายการ (ลงรายการได้ / บัญชีคุม)
- **การนำทางด้วยคีย์บอร์ด (Keyboard First)**:
  - `↑` / `↓` เลื่อนแถวที่ไฮไลต์
  - `Enter` เลือกบัญชีที่ไฮไลต์ทันที
  - `Esc` ปิดหน้าต่าง
  - ดับเบิ้ลคลิกแถวเพื่อเลือกทันที
- **รองรับทั้ง Single-Select และ Multi-Select**:
  - โหมดเลือกเดี่ยวสำหรับสมุดรายวัน, รายงาน, ผังบัญชี
  - โหมดเลือกหลายรายการสำหรับแถวในงบการเงิน (`gl-statement-designer`)

### 2. การเชื่อมต่อกับ `AccountSelect` (`frontend/src/app/gl/gl-common.tsx`)
- เพิ่มปุ่มค้นหาผังบัญชี `[ 🔍 ]` ที่มุมขวาของตัวเลือก
- ดักจับ `onMouseDown` และ `onKeyDown` (`F2`, `Space`, `Enter`) เพื่อเปิด `AccountSearchDialog` ทันทีที่ผู้ใช้คลิก
- ยังคง `<select aria-label={label}>` ไว้ใน DOM เพื่อความเข้ากันได้ 100% กับ Playwright E2E Tests (`locator.selectOption(...)`)
- มีปุ่มเคลียร์ค่า `[ ✕ ]` เมื่อมีบัญชีถูกเลือกอยู่

### 3. การเชื่อมต่อกับหน้าออกแบบงบการเงิน (`gl-statement-designer.tsx`)
- นำ `AccountSearchDialog` ในโหมด `multiSelect={true}` เข้ามาแทนที่ modal ชั่วคราวเดิม ทำให้ผู้ใช้ออกแบบงบสามารถค้นหาและผูกผังบัญชีเข้ากับแถวงบได้อย่างสะดวกสบายและเต็มจอ
