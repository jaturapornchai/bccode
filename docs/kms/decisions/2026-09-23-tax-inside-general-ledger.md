# เมนูภาษีทั้งหมดอยู่ในหมวด "บัญชีแยกประเภท" — ผู้ใช้ GL ตัวเดียวใช้ได้เลย

## Context

- ลุงจืดสั่ง (2026-09-23): "ทุกอย่าง ต้องอยู่ในระบบ บัญชีแยกประเภท เพราะต้องการให้ คนใช้ GL ตัวเดียว ใช้ได้เลย เช่นสำนักงานบัญชี ส่วนระบบอื่นๆ ยังไม่ต้องทำ"
- `mydocs/specs/gl/spec.md`: "ผู้ทำบัญชีคนเดียวใช้งานได้ตามสิทธิ์ ไม่ต้องติดตั้งระบบอื่นก่อน"; `tax-design-notes.md`: VAT/WHT เป็นรายละเอียดประกอบใบสำคัญ
- Champ (`D:\project-champ\champ\champ\menuconfigxml\menuconfig.xml` บรรทัด 552–615): เมนู "ปรับปรุงภาษีซื้อ", "พิมพ์ภาษีหัก ณ ที่จ่าย (ภ.ง.ด.3, ภ.ง.ด.53)" และกลุ่ม "รายงานภาษี" อยู่ **ใต้ popup GL**

## Decision

1. ยุบหมวด `vat` — ย้ายกลุ่ม `vat-transactions` (บันทึกภาษี) และ `vat-reports` (รายงานภาษีและแบบยื่น) ไปท้ายหมวด `gl` (`frontend/src/lib/menu-data.ts`); id/route/language key ของทุกเมนูคงเดิม (สิทธิ์เดิมไม่เปลี่ยน, ยังคง 194 รายการ)
2. `GL_MENU_ITEMS` นับเฉพาะกลุ่ม `gl-*` (จอ GL เปิดเอง) — กลุ่มภาษียังใช้จอภาษีเดิม (`frontend/src/lib/general-ledger.ts`)
3. ป้าย "รอเชื่อมข้อมูล" ของแบบภาษีสะท้อนแหล่งข้อมูลจริง: ภ.ง.ด.2/3/53, 50 ทวิ, ภาษีถูกหัก อ่านจาก GL (`gl_lines`) = พร้อม; ภาษีซื้อ/ภาษีขาย/ภ.พ.30/ภ.พ.36 ยังอ่านตารางเอกสารของระบบอื่น = รอเชื่อมข้อมูล (bug เปิดอยู่ `docs/kms/bugs/2026-09-23-vat-report-reads-missing-erp-tables.md`)
4. รายงาน WHT เรียก `generalledger.EnsureSchema` ก่อน query — กลุ่มกิจการใหม่ที่ยังไม่เคยเปิด GL เห็นรายงานว่าง ไม่ใช่ 500 (`relation "gl_records" does not exist`)
5. ทางลัดเริ่มต้นหน้าแรกไม่แสดงจอ "รอพัฒนา" (`frontend/src/app/menu/dashboard-home.tsx`, `manage-shortcuts-screen.tsx`)

## Alternatives

- **คงหมวดภาษีแยก** — ตรงกับ ERP ทั่วไป แต่ขัดคำสั่งลุงจืดและผัง Champ → ไม่เลือก
- **ย้าย VAT ไปอ่าน GL ในรอบนี้เลย** — ต้องสร้างรายละเอียด VAT ในใบสำคัญตาม `mydocs/datamodels/gl/vat.sql` ซึ่งยังมีข้อที่ลุงจืดต้องตัดสิน (scale/ปัดเศษ/ประเภทภาษีซื้อ) → แยกเป็นงานถัดไป

## Consequences

- สำนักงานบัญชีที่ใช้ GL อย่างเดียวเข้าเมนูภาษีได้ในหมวดเดียว; หมวดหลักเหลือ 8 หมวด
- ภาษีซื้อ/ขาย/ภ.พ.30 ยังใช้ไม่ได้จนกว่าจะทำ VAT ใน GL — **อัปเดตวันเดียวกัน:** ทำแล้ว (`details.vats` ในใบสำคัญ → รายงานภาษีซื้อ/ขาย + แบบ ภ.พ.30 ผ่าน `/api/report/tax/form/*`, ADR `2026-09-23-rd-tax-forms-engine.md`)
