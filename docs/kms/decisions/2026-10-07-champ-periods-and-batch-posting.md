# งวดบัญชีสร้างอัตโนมัติ + ผ่านรายการทีละชุดแบบ Champ (5511 / 5512)

## Context
ลุงจืดสั่ง 2026-10-07 "ออกแบบใหม่ให้ Champ เป็นหลัก" — เดิม BC ให้ผู้ใช้สร้างงวดทีละงวดเองในจอข้อมูลหลัก และผ่านรายการได้ทีละใบจากจอสมุดรายวัน ขณะที่ Champ (`docs/kms/champ/09-gl.md`):
- 5511 กำหนดงวดบัญชี: ตารางงวดของปี + สร้างงวดรายเดือนจากช่วงวันของปีบัญชี
- 5512 ผ่านรายการ: เลือกเงื่อนไข (สมุด/วันที่/เลขที่) → ตรวจ → เลือก → ผ่านทั้งชุด

## Decision
- **งวด** (`backend/internal/generalledger/periods_generate.go`): สร้างปีบัญชีแล้วได้งวดเดือนละงวดอัตโนมัติ; ปุ่ม "สร้างงวดอัตโนมัติ (F9)" เติมเดือนที่ขาดใน `sql.Tx` เดียว ข้ามเดือนที่มีแล้ว, งวดที่ช่วงวันคร่อมเดือน → ปฏิเสธ (`period_generate_overlap`); แก้วันของปีที่มีงวดล็อกอยู่ไม่ได้; ล็อก/ปลดล็อกต้องมีเหตุผลทุกครั้ง (เก็บใน `gl_events.reason`); จอ `frontend/src/app/gl/gl-periods.tsx` (`/gl/periodlock`)
- **ผ่านรายการทีละชุด** (`backend/internal/generalledger/post_batches.go`): `check` = ลองผ่านจริงทีละใบใน tx แล้ว rollback (กฎเดียวกับผ่านทีละใบ ไม่เขียนกฎซ้ำ); `post` = ผ่านทุกใบที่เลือกใน tx เดียว **ใบไหนไม่ผ่าน = ไม่ผ่านเลยทั้งชุด**; ชุดละ ≤ 200 ใบ; เลขชุด `000001…` เก็บเป็น record `post-batches` และใส่ `postbatchno` ในแต่ละใบ; จอ `frontend/src/app/gl/gl-post-batch.tsx` (`/gl/posting`, ปุ่ม F7 ตรวจ / F2 เลือกทั้งหมด / F11 ผ่าน)
- การยกเลิกใบที่ผ่านแล้วยังเป็น **ใบกลับรายการ** (แท็บ "กลับรายการที่ผ่านแล้ว") ไม่ใช่ถอยสถานะกลับเป็นร่างแบบ Champ 5513 — ตามสเปก GL ที่ใบผ่านแล้วแก้ด้วยรายการกลับเท่านั้น

## Alternatives
- ผ่านบางใบที่ผ่านได้ แล้วรายงานใบที่ไม่ผ่าน (แบบ Champ) — ผู้ใช้ไม่รู้ว่าชุดไหนเข้าไปแล้วบ้าง; all-or-nothing ตรวจสอบย้อนหลังง่ายกว่า (ปุ่มตรวจสอบบอกปัญหาก่อนอยู่แล้ว)
- งวดตั้งชื่อเอง/ไม่ใช่เดือนปฏิทิน — Champ 5511 สร้างรายเดือน; ปีหนึ่งจำกัด 24 งวด

## Consequences
- จอข้อมูลหลักงวดแบบเดิม (สร้าง/แก้งวดเอง) ถูกตัดออก — งวดมาจากปีบัญชีเท่านั้น
- ทดสอบ: `periods_generate_test.go`, `post_batches_integration_test.go`, `gl-periods.test.ts`, `gl-post-batch.test.ts`; UAT 2026-10-07 บน local: สร้างงวด 10 งวด (ปี 2569 ครบ 12), ล็อก/ปลดล็อกพร้อมเหตุผล, ตรวจ 2 ใบไม่เปลี่ยนสถานะ, ผ่านชุด `000001` 2 ใบ → `gl_lines` 4 แถว + `postbatchno`
