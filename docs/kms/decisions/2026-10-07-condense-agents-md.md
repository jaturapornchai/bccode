# ADR 2026-10-07: ย่อ AGENTS.md เพื่อลด token — เนื้อหาเต็มย้ายไป docs/kms/rules/agents-full.md

- **สถานะ:** ใช้งาน (ลุงจืดสั่ง 2026-10-07 "แก้ไขเลยให้ประหยัด token แล้วทำต่อ ให้ใช้ model เล็กๆ มาช่วยเสมอ")
- **บริบท:** วัด transcript session 2026-10-07 (1,093 การเรียก): ค่าใช้จ่ายหลักคือ cache read = จำนวนครั้งที่เรียก × context เฉลี่ย ~244k token; context ขั้นต่ำหลัง compact ~125–135k ต่อครั้ง และ `AGENTS.md` (130 KB, ไทย 33k ตัวอักษร) ถูก import ผ่าน `CLAUDE.md` ทุกการเรียก
- **ตัดสินใจ:** `AGENTS.md` เหลือกฎแบบ bullet สั้น (~15k ตัวอักษร, 25 KB) ครบทุกหัวข้อพร้อมวันที่ตั้งกฎ ร่างโดย agent sonnet ตรวจโดย Opus; เนื้อหาเดิมทั้งหมด (เหตุผล ตัวอย่าง ประวัติสถานะ) ย้ายไป `docs/kms/rules/agents-full.md` ให้เปิดเฉพาะหัวข้อที่ต้องใช้; ชื่อแบรนด์คู่แข่งในฉบับเต็มแทนด้วย [แบรนด์คู่แข่ง] เพราะ pre-commit guard ยกเว้นเฉพาะ `AGENTS.md`
- **ทางเลือกที่ไม่เลือก:** (1) แยกกฎเป็นหลายไฟล์ใน `.agents/rules/` — ขัดกฎ "กฎอยู่ที่เดียว" (2) ตัดกฎทิ้ง — เสี่ยงลืมข้อห้ามของลุงจืด
- **ผลที่ตามมา:** ทุก AI โหลดกฎน้อยลง ~100 KB ต่อการเรียก; ฉบับเต็มอาจเก่าได้ — ถ้าขัดกัน `AGENTS.md` ชนะ; แก้กฎใหม่ให้เขียนที่ `AGENTS.md` แบบสั้น และใส่เหตุผลยาวใน ADR แทน
- **ร่วมกัน:** `autoCompactWindow` ใน `~/.claude/settings.json` 400000 → 250000 (นอก repo, สำรอง `settings.json.bak-2026-10-07`)
