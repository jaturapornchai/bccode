# งบการเงินจากรูปแบบงบคำนวณที่ backend + คอลัมน์ปีก่อน + แม่แบบตามแบบ 2 (ประกาศกรมพัฒนาธุรกิจการค้า พ.ศ. 2566)

## Context

- ตรวจรายงาน GL (`docs/kms/20-champ-parity-gap.md` §7.2 ข้อ 2): จอ "ออกแบบงบการเงิน" (`/gl/statement-designer`) คำนวณงบ **ในเบราว์เซอร์** (`calculateStatement` ใน `frontend/src/lib/general-ledger.ts`) จากงบทดลอง — ผิดกฎ backend-first และมีบั๊กจริง:
  - แถว `__current_earnings__` (กำไรที่ยังไม่ปิดบัญชี) เป็น 0 เสมอ เพราะงบทดลองไม่มีแถวนี้
  - งบกำไรขาดทุนของปีที่ปิดบัญชีแล้วเป็น 0 (ยอดคงเหลือหลังรายการปิดบัญชี)
  - เลือกช่วงกลางปี งบกำไรขาดทุนยังเป็นยอดสะสมจากต้นปี
  - ค่า `comparisontype` ในรูปแบบงบไม่ถูกใช้ (ไม่มีคอลัมน์ปีก่อน)
  - ปุ่ม "พิมพ์งบการเงิน" เรียก `window.print()` เปล่า ๆ → พิมพ์ทั้งหน้าแอป
  - แม่แบบเริ่มต้นใส่รหัสบัญชีสมมุติ (เช่น `1111-01`) ซึ่งผังบัญชีของแต่ละกิจการไม่มีจริง
- **Champ (ต้นแบบ)** มีแค่ตัวออกแบบงบทั่วไป (เมนู 5505, `FSMainDlg`/`MyXpFinanceSheet`) อ้างยอดปีก่อนด้วย token `YEAR(<code>)` ในช่อง — ไม่มีงบการเปลี่ยนแปลงส่วนของผู้ถือหุ้นและหมายเหตุ
- **กฎหมาย/มาตรฐาน** (ทะเบียน `DBD-FS-2566` และ `TFRS-NPAES-4` ใน `docs/kms/21-thai-tax-form-references.md`):
  - ประกาศกรมพัฒนาธุรกิจการค้า เรื่อง กำหนดรายการย่อที่ต้องมีในงบการเงิน พ.ศ. 2566 (ลงวันที่ 27 ต.ค. 2566, ราชกิจจานุเบกษา เล่ม 140 ตอนพิเศษ 288 ง หน้า 24–26) — ข้อ 9 ใช้กับงบการเงินที่รอบปีบัญชีเริ่มในหรือหลัง 1 ม.ค. 2567; บริษัทจำกัดใช้ **แบบ 2**: งบฐานะการเงิน, งบกำไรขาดทุน, งบการเปลี่ยนแปลงส่วนของผู้ถือหุ้น, หมายเหตุ พร้อมตัวเลขปีก่อนเปรียบเทียบ; ข้อ 7 รายการที่กิจการไม่มีไม่ต้องแสดง
  - TFRS for NPAEs ย่อหน้า 4.1 (งบที่ต้องมี: งบแสดงฐานะการเงิน/งบกำไรขาดทุน/งบแสดงการเปลี่ยนแปลงส่วนของเจ้าของ/หมายเหตุ), 4.2 (ไม่บังคับงบกระแสเงินสด), 4.3 (ข้อมูลเปรียบเทียบ), 4.7 (หัวงบ: ชื่องบ ชื่อกิจการ วันสิ้นงวด สกุลเงิน จำนวนหลัก)
  - ไม่มีแหล่งใดใช้คำว่า "งบดุล"

## Decision

1. **คำนวณงบที่ backend** — `GET /gl/v2/reports/statement?template=<รหัสรูปแบบ>&fiscalyear=&from=&to=&branchcode=&departmentcode=&projectcode=` (`backend/internal/generalledger/statements.go`)
   - ยอดต่อบัญชีจาก `gl_lines` คำสั่ง SQL เดียว: ยอดคงเหลือ ณ `to` และความเคลื่อนไหวในช่วง `from..to` ที่ไม่นับรายการยกมา/ปิดบัญชี (`kind NOT IN ('opening','closing')`)
   - งบกำไรขาดทุน/ต้นทุนผลิต (`pnl`, `production_cost`) ใช้ความเคลื่อนไหวในช่วง; งบอื่นใช้ยอดคงเหลือ
   - `__current_earnings__` = ผลรวมรายได้/ค่าใช้จ่ายที่ยังไม่ปิด (แบบเดียวกับรายงาน `balancesheet`)
   - สูตร `Rnn`, `+ - * / ( )`, `SUM(Ra:Rb)`/`SUM(a..b)` ด้วย `shopspring/decimal` (คูณตัดที่ 8 ตำแหน่ง, หารด้วย `QuoRem` 8 ตำแหน่ง, หารศูนย์/อ้างตัวเอง/token แปลก = 0)
   - แสดงผลปัดครึ่งขึ้นห่างศูนย์ (`StringFixed`) ที่ทศนิยมของรูปแบบงบ (ค่าเริ่ม 2) ทีละแถว
2. **คอลัมน์ปีก่อน** เมื่อรูปแบบตั้ง `comparisontype: "previous_year"` — ปีก่อน = ปีบัญชีที่สิ้นสุดล่าสุดก่อนวันเริ่มปีปัจจุบัน; เลือกทั้งปี → เทียบทั้งปีก่อน, เลือกช่วงย่อย → ช่วงเดียวกันย้อน 1 ปี (คงวันสิ้นเดือน ก.พ. 28/29) และตัดให้อยู่ในปีก่อน; ไม่มีปีก่อน → คอลัมน์เดียว + คำเตือน; `report.periods` บอกช่วงของแต่ละคอลัมน์
3. **frontend แสดงผลอย่างเดียว** — ลบ engine ฝั่งเบราว์เซอร์ทั้งชุด; จอพรีวิวเรียก API จากรูปแบบที่ **บันทึกแล้ว** (แก้ค้างอยู่ = ให้บันทึกก่อน); `GLStatementTable` (`frontend/src/app/gl/gl-print.tsx`) ใช้ทั้งพรีวิวและหน้าพิมพ์ผ่าน `useGLPrint()`; หัวงบ = ชื่อกิจการ + ชื่อแม่แบบ + "ณ วันที่ …" / "สำหรับปีสิ้นสุดวันที่ …" / "สำหรับงวดตั้งแต่วันที่ … ถึงวันที่ …" + "(หน่วย : บาท)"; ศูนย์แสดง "-"; เพิ่มตัวเลือก "คอลัมน์เปรียบเทียบ" ในจอออกแบบ
4. **แม่แบบเริ่มต้น** `BS-DBD` (งบแสดงฐานะการเงิน) และ `PNL-DBD` (งบกำไรขาดทุน จำแนกตามหน้าที่ แบบหลายขั้น) เรียงรายการตามแบบ 2 **โดยไม่ใส่รหัสบัญชี** ให้ผู้ใช้เลือกบัญชีเอง (ยกเว้น `__current_earnings__` ในแถว "ยังไม่ได้จัดสรร"); แม่แบบงบต้นทุนขาย/กระแสเงินสดเดิมถูกล้างรหัสบัญชีสมมุติ
5. BFF (`/api/gl/...`, `/api/integration/gl/...`) ส่งต่อพารามิเตอร์ `template` และ `statement` อยู่ใน `GL_REPORTS`

## Alternatives considered

- **แก้ engine ในเบราว์เซอร์** — ผิดกฎ backend-first, ต้องโหลดงบทดลองทุกหน้าเข้าเบราว์เซอร์, และไม่มีข้อมูลรายการปิดบัญชี/ความเคลื่อนไหวรายช่วง
- **token ปีก่อนรายช่อง แบบ Champ `YEAR(<code>)`** — ยืดหยุ่นกว่าแต่ผู้ใช้ต้องเขียนสูตรทุกแถว; แบบ 2 ต้องการคอลัมน์ปีก่อนทั้งงบอยู่แล้ว
- **จับคู่บัญชีเข้าบรรทัดงบจากรหัส/ชื่อบัญชีอัตโนมัติ** — ห้าม (กฎไม่ใช้รหัส/ชื่อบัญชีเป็นเงื่อนไข; ผังบัญชีแต่ละกิจการไม่เหมือนกัน)

## Consequences

- ✅ งบกำไรขาดทุนปีที่ปิดแล้ว/ช่วงกลางปี/กำไรที่ยังไม่ปิด ถูกต้อง; มีคอลัมน์ปีก่อน; พิมพ์เฉพาะงบบนกระดาษ A4
- ⚠️ **ยังไม่มี** งบการเปลี่ยนแปลงส่วนของผู้ถือหุ้น (ต้องรู้ว่าบัญชีไหนเป็นทุนชำระแล้ว/ส่วนเกินมูลค่าหุ้น และรายการไหนเป็นเงินปันผล/เพิ่มทุน — ระบบยังไม่มีข้อมูลนี้ ห้ามเดา) และหมายเหตุประกอบงบ (ต้องมีที่เก็บข้อความ) — รอลุงจืดตัดสิน
- ⚠️ ชื่อเมนู `/report/balancesheet` ยังเป็น "งบดุล" ตามถ้อยคำ Champ; แบบ 2 ใช้ "งบฐานะการเงิน" ส่วน TFRS for NPAEs ใช้ "งบแสดงฐานะการเงิน" — รอลุงจืดเลือก
- ⚠️ แม่แบบงบต้นทุนขาย/กระแสเงินสดเดิมยังออกแบบผิดหลัก (ใช้ยอดคงเหลือเป็น "ต้นงวด"/"การเปลี่ยนแปลง") — ไม่บังคับตาม TFRS for NPAEs 4.2 จึงยังไม่แก้
- ⚠️ ยอดที่แสดงปัดทีละแถว — แถวสูตรที่มีคูณ/หารอาจต่างจากผลรวมแถวที่ปัดแล้วได้ไม่เกินเศษสตางค์ (บัญชีปกติเป็น 2 ตำแหน่งอยู่แล้วจึงไม่ต่าง)
