# กฎ: ยึด D:\project-champ เป็นต้นแบบหลัก ไม่เพิ่มฟังก์ชันหรือเมนูมากเกินไป (Upgrade จาก Windows สู่ Web)

## ที่มา

ลุงจืดสั่ง 2026-09-19:
*"ตั้งกฏ ไม่เพิ่มมากเกินไปจาก D:\project-champ เพราะ project นี้เป็นการ upgrade จาก windows -> web"*

ก่อนหน้านี้ ในระบบมีแนวโน้มที่ AI แต่ละตัวจะคิดฟังก์ชันใหม่, เมนูใหม่, หน้าจอย่อย, แดชบอร์ด หรือรายงานแปลกๆ เข้ามาเอง เช่น ในระบบบัญชีแยกประเภท (GL) ที่มีเมนูบวมไปถึง 33 รายการ (มีทั้ง Daily Check, สำรองข้อมูล, กราฟ, ประมาณการกระแสเงินสด, Dashboard, Executive Summary, ปันส่วน, กลุ่มบัญชี) ส่งผลให้:
1. ผู้ใช้งานจริง (นักบัญชีและเจ้าของกิจการที่เคยใช้ Champ บน Windows) เกิดความสับสนอย่างมาก หาเมนูหลักไม่เจอ
2. ระบบเกิดความซับซ้อนเกินจำเป็น (Over-Engineering / Feature Bloat)
3. ทรัพยากรและเวลาในการพัฒนาถูกเบี่ยงเบนไปจากเป้าหมายหลัก

## เจตนารมณ์และหลักการ

โปรเจกต์ BC Ai Account เป็นการ **Upgrade ระบบจากโปรแกรม Desktop บน Windows (`D:\project-champ`) มาสู่ Web Application ยุคใหม่**
เป้าหมายคือ: **"ทำให้ผู้ใช้ทำงานตาม workflow บัญชีเดิมของ Champ ได้เร็วกว่าเดิม ง่ายกว่าเดิม สบายตากว่าเดิม และปลอดภัยยิ่งขึ้นบน Web"**

ไม่ใช่การสร้างระบบใหม่ที่ยัดเยียดฟังก์ชันเรื่อยเปื่อยจนกลายเป็นเขาวงกต

## ข้อกำหนดและแนวทางปฏิบัติ (Mandatory Guidelines)

1. **Strict Parity — No Feature Bloat (ห้ามเพิ่มฟังก์ชัน/เมนูเกิน Champ เอง)**:
   - ห้ามคิดฟังก์ชันใหม่, เมนูใหม่, จอย่อย หรือฟิลด์แปลกๆ เข้ามาเองโดยไม่ได้รับอนุมัติ
   - ยึด `D:\project-champ` (เมนูใน `champ/champ/menuconfigxml/menuconfig.xml`, ซอร์สโค้ด C++/MFC, สคริปต์ฐานข้อมูล DDL) เป็น Baseline เสมอ
   - หาก Champ ไม่มี และไม่ได้มีคำสั่งเฉพาะเจาะจงจากลุงจืด หรือไม่ใช่ข้อบังคับทางกฎหมายบัญชี/ภาษีไทย ห้ามใส่เข้ามาเด็ดขาด (ยึดหลัก Minimal Change และ YAGNI 100%)

2. **โฟกัสที่การยกระดับประสบการณ์บน Web (Modern Web Parity Focus)**:
   - จุดที่ต้องพัฒนาให้เหนือกว่า Desktop Windows เดิม คือ:
     - **ความเร็ว (Sub-second Performance)**: โหลดหน้าจอไว ค้นหาเร็ว สตรีมมิ่ง deploy ไร้การเขียนดิสก์
     - **UX/UI สวยงามและเข้ากับคนไทย 40+**: ตัวหนังสืออ่านง่าย คอนทราสต์ชัด มีมิติเงานุ่มนวล
     - **Speed Entry & Tab Navigation**: ป้อนข้อมูลลื่นไหลด้วย Numpad / Tab Flow ต่อเนื่อง, Auto-Balance เดบิต-เครดิตอัตโนมัติ, Smart Paste จาก Excel
     - **Web Security**: HttpOnly Cookies, Parameterized SQL / Mongo Prepared Queries 100%

3. **Streamline over Expansion (ยุบรวมสิ่งที่ซ้ำซ้อน)**:
   - หากหน้าจอหรือเมนูเดิมของ Champ มีความซ้ำซ้อน ให้ยุบรวมเป็นหน้าจอเดียวที่มี Tab สลับชัดเจน (เช่น รวมหน้าผ่านรายการและยกเลิกเข้าด้วยกันเป็น `/gl/posting`, การตัดกลุ่มผังบัญชีออกเพื่อจัดต้นไม้ด้วย Level & Prefix อัตโนมัติ)

4. **Propose First, Never Impose (ถามลุงจืดก่อนทำของใหม่)**:
   - หาก AI มองเห็นฟีเจอร์สมัยใหม่ที่อาจมีประโยชน์แต่ Champ ไม่มี ต้องนำเสนอเป็นคำแนะนำ (Proactive Advice) พร้อมระบุข้อดี-ข้อเสียให้ลุงจืดตัดสินใจก่อนเสมอ ห้ามแอบเขียนโค้ดเพิ่มเข้ามาเองในระบบ
