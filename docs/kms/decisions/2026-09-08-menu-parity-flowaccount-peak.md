# เพิ่มเมนู 19 รายการให้ BC ครอบคลุมงานหลักของ FlowAccount + PEAK

## Context

ลุงจืดถามว่า "ตอนนี้ menu bc ครบเท่า flowaccount + peak หรือยัง ถ้ายังเพิ่มให้ครบ" — ก่อนหน้านี้ commit `20b9fd3d` (2026-09-07) เทียบรอบแรกและเพิ่มเมนูบัญชี/ภาษี/สินทรัพย์/ธนาคารไปแล้ว 33 รายการ แต่ยังไม่ได้เทียบครบทั้งผลิตภัณฑ์

รอบนี้อ่านหน้าทางการของทั้งสองเจ้าจริง (flowaccount.com help center/pricing/functions, peakaccount.com peak-manual/หน้าผลิตภัณฑ์) ได้ฟีเจอร์ 411 รายการ เทียบกับ `frontend/src/lib/menu-data.ts` แล้วให้ผู้ตรวจอิสระพยายามหักล้างทุกช่องว่าง (ตรวจซ้ำทั้งฝั่งเมนู BC และฝั่งหลักฐานเว็บ) เหลือช่องว่างที่ยืนยัน 20 ข้อ

## Decision

- เพิ่มเมนู **19 รายการ** และกลุ่มใหม่ 1 กลุ่ม ("เงินเดือนและพนักงาน" ใต้ งานประจำ) → เมนูรวม 185 → 204 รายการ (รายละเอียดใน `docs/kms/19-menu-coverage-flowaccount-peak.md`)
- **เพิ่มเฉพาะรายการเมนู ไม่สร้างจอ/ไม่สร้างกฎธุรกิจ** — รายการที่กฎยังไม่ชัด (เงินเดือน, ภ.ง.ด.1, ประกันสังคม, XBRL, ไฟล์ธนาคาร, ระดับการอนุมัติ) เปิดเป็นเมนูไว้ก่อนและบันทึกคำถามไว้ ห้ามเดากฎ (Rule 1 NO MAGIC + Rule 17 THAI-DOMAIN)
- **ไม่เพิ่ม** ล็อตสินค้า/วันหมดอายุ, รายงานส่งอีเมลอัตโนมัติ, ส่งออก/สำรองข้อมูลกิจการ — ตัวตรวจสอบชนขีดจำกัดการใช้งานระหว่างรอบ ยังไม่มีหลักฐานยืนยัน
- ของที่คู่แข่งมีแต่ BC วางไว้นอกเมนูโดยตั้งใจ (ทะเบียนพนักงาน `/employee`, จอ LINE `/line-oa`) ถือว่าครอบคลุมแล้ว ไม่ย้ายเข้าเมนู

## Alternatives

- เพิ่มทั้ง 20 ข้อรวมโมดูลเงินเดือนเต็มรูปแบบ — ปฏิเสธ: กฎภาษี/ประกันสังคมต้องยืนยันกับประกาศราชการก่อน และเกินขอบเขตคำสั่ง (Rule 4)
- ไม่เพิ่มอะไรจนกว่าจะมีจอจริง — ปฏิเสธ: BC ใช้เมนูเป็นแผนผังงานอยู่แล้ว เมนูที่ยังไม่มีจอแสดงการ์ด "Flutter route เดิม" ซึ่งเป็นแพทเทิร์นเดิมของระบบ

## Consequences

- ✅ แผนผังเมนูเทียบเท่าคู่แข่งทั้งสองเจ้าและยังมีส่วนที่เหนือกว่า (POS/ร้านอาหาร, BOQ, marketplace, FIFO layers, สินค้าชุด/BOM)
- ⚠️ เมนูใหม่ยังไม่มีจอจริง ผู้ใช้กดแล้วเห็นการ์ด placeholder — ถ้าจะให้ลูกค้าเห็น ต้องเลือกว่าจะซ่อนหรือทำจอก่อน
- ⚠️ คำแปล 12 ภาษาของ key ใหม่เขียนโดย AI ยังไม่มีเจ้าของภาษาตรวจ (ภาษาไทย/อังกฤษตรวจแล้ว)
- ⚠️ backend ที่รันอยู่จะยังไม่มี key ใหม่จนกว่าจะ rebuild image (frontend fallback เป็นป้ายไทยในโค้ดจึงยังแสดงถูก)
