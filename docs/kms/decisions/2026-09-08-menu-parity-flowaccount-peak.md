# เพิ่มเมนู 15 รายการให้ BC ครอบคลุมงานหลักของ FlowAccount + PEAK และตัดระบบเงินเดือนออกจากขอบเขต

> ⚠️ **ถูกต่อยอดอีก 2 รอบในวันเดียวกัน — อย่าอ่านเลข 200 ในไฟล์นี้เป็นสถานะปัจจุบัน:** 200 → **218** (commit `3217fd04` ชุด 18 รายการ ปิดช่องว่างที่เหลือจากหลักฐานหน้าเว็บทางการ ไม่มี ADR แยก รายละเอียดอยู่ใน [`19-menu-coverage-flowaccount-peak.md`](../19-menu-coverage-flowaccount-peak.md)) → **224** (commit `098107e1` ดู ADR ต่อเนื่อง [2026-09-08-menu-parity-social-sweep.md](2026-09-08-menu-parity-social-sweep.md)) · **ยอดปัจจุบัน = 224** ตรวจได้ที่ `frontend/src/lib/menu-icons.test.ts:10` · ส่วนการตัดสินใจ **"ไม่ทำระบบเงินเดือน" ยังมีผลเต็มตามเดิม**

## Context

ลุงจืดถามว่า "ตอนนี้ menu bc ครบเท่า flowaccount + peak หรือยัง ถ้ายังเพิ่มให้ครบ" — ก่อนหน้านี้ commit `20b9fd3d` (2026-09-07) เทียบรอบแรกและเพิ่มเมนูบัญชี/ภาษี/สินทรัพย์/ธนาคารไปแล้ว 33 รายการ แต่ยังไม่ได้เทียบครบทั้งผลิตภัณฑ์

รอบนี้อ่านหน้าทางการของทั้งสองเจ้าจริง (flowaccount.com help center/pricing/functions, peakaccount.com peak-manual/หน้าผลิตภัณฑ์) ได้ฟีเจอร์ 411 รายการ เทียบกับ `frontend/src/lib/menu-data.ts` แล้วให้ผู้ตรวจอิสระพยายามหักล้างทุกช่องว่าง (ตรวจซ้ำทั้งฝั่งเมนู BC และฝั่งหลักฐานเว็บ) เหลือช่องว่างที่ยืนยัน 20 ข้อ

หลังเสนอผล ลุงจืดสั่งเพิ่มเติมในวันเดียวกันว่า **"ไม่เอาระบบเงินเดือน"**

## Decision

- เพิ่มเมนู **15 รายการ** → เมนูรวม 185 → 200 รายการ (รายละเอียดใน `docs/kms/19-menu-coverage-flowaccount-peak.md`) *(เลข 200 คือยอด ณ commit `c74298a1` ของรอบนี้ — ยอดปัจจุบันคือ 224 ดูคำเตือนใต้หัวเรื่อง)*
- **ไม่ทำระบบเงินเดือน (payroll)** — ไม่มีกลุ่ม "เงินเดือนและพนักงาน", ไม่มีคำนวณเงินเดือน/สลิป และไม่มีแบบยื่นที่เป็นผลจากเงินเดือน (**ภ.ง.ด.1**, **ไฟล์นำส่งประกันสังคม**) เพราะไม่มีข้อมูลต้นทางในระบบ; language key `payroll*` ที่ค้างจากรอบก่อนถูกลบทิ้งด้วย — เป็นความต่างจากคู่แข่งที่ยอมรับแล้ว **ห้ามเพิ่มกลับเอง**
- คงไว้: "เงินทดรองจ่ายพนักงาน" (งานการเงิน ไม่ใช่เงินเดือน) และ ภ.ง.ด.3/53 + 50 ทวิ ของผู้ขาย ที่มีอยู่เดิม
- **เพิ่มเฉพาะรายการเมนู ไม่สร้างจอ/ไม่สร้างกฎธุรกิจ** — รายการที่กฎยังไม่ชัด (XBRL, ไฟล์ธนาคาร, ระดับการอนุมัติ, เทมเพลตนำเข้าเอกสาร) เปิดเป็นเมนูไว้ก่อนและบันทึกคำถามไว้ ห้ามเดากฎ (Rule 1 NO MAGIC + Rule 17 THAI-DOMAIN)
- ~~**ไม่เพิ่ม** ล็อตสินค้า/วันหมดอายุ, รายงานส่งอีเมลอัตโนมัติ, ส่งออก/สำรองข้อมูลกิจการ — ตัวตรวจสอบชนขีดจำกัดการใช้งานระหว่างรอบ ยังไม่มีหลักฐานยืนยัน~~ **(ล้มเลิกในชุด 18 รายการวันเดียวกัน commit `3217fd04` — เพิ่มเข้าเมนูครบทั้งสามเรื่องแล้ว: `stock-lot` `/inventory/lotexpiry` (`frontend/src/lib/menu-data.ts:135`), `expiring-stock-alert` `/report/expiringstock` (:258), `stock-lot-movement` `/report/stocklotmovement` (:261), `data-backup-export` `/tools/databackup` (:349), `automated-report-email` `/tools/scheduledreports` (:358); ดูรายการ 1-3 และ 12-13 ใน [`19-menu-coverage-flowaccount-peak.md`](../19-menu-coverage-flowaccount-peak.md) — อย่าเพิ่มซ้ำ และอย่าถอดออก)**
- ~~ของที่คู่แข่งมีแต่ BC วางไว้นอกเมนูโดยตั้งใจ (ทะเบียนพนักงาน `/employee`, จอ LINE `/line-oa`) ถือว่าครอบคลุมแล้ว ไม่ย้ายเข้าเมนู~~ **(กลับคำในชุด 18 รายการวันเดียวกัน commit `3217fd04` — ย้ายเข้าเมนูทั้งคู่แล้ว: `employee-registry` ในกลุ่มใหม่ "บุคลากรและผู้ใช้งาน" (`id: organization-people`) ใต้ "ข้อมูลหลัก" — `frontend/src/lib/menu-data.ts:373-376` และ `line-official-account` ในกลุ่ม "ผู้ช่วย AI และคลังความรู้" — `menu-data.ts:359`; ดูรายการ 14-15 ใน [`19-menu-coverage-flowaccount-peak.md`](../19-menu-coverage-flowaccount-peak.md) · ทะเบียนพนักงานในเมนูไม่ขัดกฎ "ไม่ทำเงินเดือน" เพราะเป็นทะเบียนข้อมูลหลัก ไม่ใช่การคำนวณค่าจ้าง อย่าลบทิ้ง)**

## Alternatives

- ทำโมดูลเงินเดือนเต็มรูปแบบตาม FlowPayroll / PEAK Payroll — ปฏิเสธโดยลุงจืด (ขอบเขตผลิตภัณฑ์)
- เก็บเมนู ภ.ง.ด.1 / ประกันสังคมไว้แม้ไม่มี payroll — ปฏิเสธ: ไม่มีข้อมูลเงินเดือนเป็นต้นทาง เมนูจะว่างเปล่าและทำให้เข้าใจผิดว่าระบบยื่นให้ได้
- ไม่เพิ่มอะไรจนกว่าจะมีจอจริง — ปฏิเสธ: BC ใช้เมนูเป็นแผนผังงานอยู่แล้ว เมนูที่ยังไม่มีจอแสดงการ์ด "Flutter route เดิม" ซึ่งเป็นแพทเทิร์นเดิมของระบบ

## Consequences

- ✅ แผนผังเมนูเทียบเท่าคู่แข่งทั้งสองเจ้าในทุกหมวดที่อยู่ในขอบเขต **เท่าที่หลักฐานหน้าเว็บทางการรอบนี้ครอบคลุม** และยังมีส่วนที่เหนือกว่า (POS/ร้านอาหาร, BOQ, marketplace, FIFO layers, สินค้าชุด/BOM) — **ห้ามเขียนว่า "ครบ 100%"** เพราะรอบกวาดแหล่งนอกเว็บทางการยังเจอช่องว่างจริงอีก 3 เรื่อง (ดู [2026-09-08-menu-parity-social-sweep.md](2026-09-08-menu-parity-social-sweep.md))
- ⚠️ ลูกค้าที่ต้องการเงินเดือน/ภ.ง.ด.1/ประกันสังคม ต้องใช้โปรแกรมอื่นคู่กัน — ทีมขายต้องรู้ข้อนี้
- ⚠️ เมนูใหม่ยังไม่มีจอจริง ผู้ใช้กดแล้วเห็นการ์ด placeholder — ถ้าจะให้ลูกค้าเห็น ต้องเลือกว่าจะซ่อนหรือทำจอก่อน
- ⚠️ คำแปล 12 ภาษาของ key ใหม่เขียนโดย AI ยังไม่มีเจ้าของภาษาตรวจ (ภาษาไทย/อังกฤษตรวจแล้ว)
- ⚠️ backend ที่รันอยู่จะยังไม่มี key ใหม่จนกว่าจะ rebuild image (frontend fallback เป็นป้ายไทยในโค้ดจึงยังแสดงถูก)
