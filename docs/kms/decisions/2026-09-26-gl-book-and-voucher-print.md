# พิมพ์สมุดบัญชี/รายงาน GL และใบสำคัญรายวันจากเบราว์เซอร์ (ตามประกาศกรมทะเบียนการค้า พ.ศ. 2544)

## Context

- ตรวจรายงาน GL เทียบ Champ (`docs/kms/20-champ-parity-gap.md` §7.2 ข้อ 1): ข้อมูลสมุดรายวัน/แยกประเภทครบ (สมุดรายวันเป็น master ที่ผู้ใช้กำหนดเอง + ตัวกรองสมุด) แต่ออกได้แค่จอกับ CSV — ไม่มีหน้าพิมพ์ และไม่มีใบสำคัญรายวันที่มีช่องลงนาม
- **Champ (ต้นแบบ)**: รายงาน GL ทุกตัวสืบจาก `CMyBaseReportView` (`champ-report/BC5REP_GLFS/GLRepGLBookView.cpp` — หัวรายงานทุกหน้า `AddDefaultHeaderItem`, นับหน้า `m_nPageCount`, ยอดรวมต่อหน้าเมื่อเปิด `IsPrintSumPage` `:181–190`)
- **กฎหมาย** (ทะเบียน `DBD-BOOKS-2544` ใน `docs/kms/21-thai-tax-form-references.md`) — ประกาศกรมทะเบียนการค้า เรื่อง กำหนดชนิดของบัญชีที่ต้องจัดทำ ข้อความและรายการที่ต้องมีในบัญชี ระยะเวลาที่ต้องลงรายการในบัญชี และเอกสารที่ต้องใช้ประกอบการลงบัญชี พ.ศ. 2544:
  - ข้อ 3: บัญชีรายวัน (เงินสด, ธนาคารแยกตามเลขที่บัญชี, ซื้อ, ขาย, ทั่วไป) และบัญชีแยกประเภท
  - ข้อ 4: ปก/หัวต้องมีชื่อผู้มีหน้าที่จัดทำบัญชี ชนิดของบัญชี และลำดับเล่ม
  - ข้อ 5: ชื่อบัญชี วัน เดือน ปี เลขที่เอกสาร/หน้าบัญชี/รหัสอ้างอิง รายการ จำนวนเงิน, **หน้าบัญชีต้องมีเลขเรียงทุกหน้า**, เงินบาท
  - ข้อ 9: เอกสารประกอบการลงบัญชีทุกประเภทต้องมีชื่อผู้จัดทำเอกสาร ชื่อเอกสาร เลขที่ (และเล่มที่ถ้ามี) วัน เดือน ปี และจำนวนเงินรวม
  - ข้อ 11: เอกสารที่ทำขึ้นใช้เอง (ใบสำคัญ) ต้องมีคำอธิบายรายการ, วิธีการและการคำนวณ (ถ้ามี), ลายมือชื่อผู้มีหน้าที่จัดทำบัญชีหรือผู้อนุมัติ

## Decision

1. **พิมพ์จากเบราว์เซอร์ด้วย portal + `@media print`** (ไม่สร้าง PDF ที่ backend) — `frontend/src/app/gl/gl-print.tsx`
   - `useGLPrint()` ต่อ `<div class="gl-print-root">` ไว้ใต้ `body` แล้วเรียก `window.print()` ผ่าน `setTimeout` (rAF ไม่ทำงานตอนแท็บถูกซ่อน); `body.gl-printing` ซ่อนแอปทั้งหมดตอนพิมพ์
   - เลขหน้า `หน้า n / N` ใช้ `@page … @bottom-right { counter(page) counter(pages) }` (Chrome 131+/Safari 18.2+) โดยป้าย "หน้า" มาจาก `languages.tsv` (`common_page`) และ escape ก่อนใส่ `<style>`
   - หัวรายงาน (ชื่อกิจการ + ชนิดบัญชี/ชื่อสมุด + ช่วงเวลา + เล่มที่ + เวลาพิมพ์) อยู่ใน `<thead>` จึงซ้ำทุกหน้า; A4 แนวตั้ง ถ้าเกิน 7 คอลัมน์ใช้แนวนอน; ตัดคอลัมน์ข้อความที่ว่างทุกแถว; ช่องเดบิต/เครดิตที่เป็นศูนย์เว้นว่าง (ยอดคงเหลือยังแสดง 0.00)
2. **ปุ่ม "พิมพ์" ในจอรายงาน GL** (`gl-reports.tsx`) — ดึงข้อมูลครบทุกหน้า (สูงสุด 10,000 แถว เหมือนส่งออก CSV) แล้วพิมพ์; รายงานสมุดรายวัน/แยกประเภทมีช่อง "เล่มที่" (ข้อ 4) ที่ไม่บังคับ — ว่างแล้วพิมพ์เป็นเส้นจุดให้เขียนเอง
3. **ปุ่ม "พิมพ์ใบสำคัญ"** ในจอดูใบสำคัญ (`gl-journals.tsx`) และหน้าต่างเจาะดูรายการจากรายงาน — ใบสำคัญรายวันมีผู้จัดทำ ชื่อสมุด เลขที่ วันที่ เอกสารอ้างอิง สาขา คำอธิบายรายการ บรรทัดบัญชี ยอดรวม (BigInt), รายละเอียด VAT/WHT (= วิธีคำนวณ ข้อ 11(2)), ป้าย "ฉบับร่าง"/"กลับรายการแล้ว" และช่องลงนาม ผู้จัดทำ/ผู้ตรวจสอบ/ผู้อนุมัติ
4. ข้อความทุกคำผ่าน key ใน `languages.tsv` (`gl_print_*`)

## Alternatives considered

- **สร้าง PDF ที่ backend (Go)** — เลขหน้า/ยอดยกไปต่อหน้าแม่นกว่า แต่ต้องเพิ่ม library + ฟอนต์ไทยใน image และ layout ซ้ำกับจอ; ยังไม่คุ้มจนกว่าจะต้องการยอดรวมต่อหน้า
- **เปิดหน้าต่างใหม่ (`window.open`) แล้วพิมพ์** — โดน popup blocker และต้องคัดลอก CSS/ฟอนต์ไปด้วย

## Consequences

- ✅ ผู้ใช้พิมพ์สมุดรายวัน/แยกประเภท/งบทดลอง/รายงาน GL ทุกตัว และใบสำคัญที่มีช่องลงนามได้ทันทีโดยไม่เพิ่ม dependency
- ⚠️ **ยังไม่มียอดรวมต่อหน้า/ยอดยกไป** แบบ Champ (`IsPrintSumPage`) — CSS คำนวณยอดต่อหน้าไม่ได้; ถ้าลุงจืดต้องการ ต้องทำ PDF ที่ backend
- ⚠️ เบราว์เซอร์เก่ากว่า Chrome 131 / Safari 18.2 ไม่พิมพ์เลขหน้า (ส่วนอื่นพิมพ์ได้ปกติ); ผู้ใช้ต้องปิด "Headers and footers" ของเบราว์เซอร์เองถ้าไม่อยากได้ URL บนกระดาษ
- ⚠️ ไม่มีปกสมุด (ข้อ 4 ใส่ไว้ที่หัวทุกหน้าแทน) และไม่เก็บประวัติการพิมพ์/เลขเล่มในฐานข้อมูล

## Verification

- `frontend/src/app/gl/gl-print.test.ts` — เลขหน้าทั้ง 2 แนว + escape `</style>`, ตัดคอลัมน์ว่าง, เว้นช่องศูนย์, ใบสำคัญ (ผู้จัดทำ ชื่อสมุด เลขที่ วันที่ ยอด 74,900.11 ด้วย BigInt, VAT, ป้ายร่าง, 3 ช่องลงนาม)
- เรนเดอร์ PDF จริงด้วย Chromium (Playwright `page.pdf({preferCSSPageSize:true})`): รายงานสมุดรายวัน JV 120 แถว = A4 แนวนอน 6 หน้า, ทุกหน้ามี "หน้า n / 6" + หัวรายงาน, ยอดรวมหน้าสุดท้าย; ใบสำคัญ = A4 แนวตั้ง 1 หน้า
- UAT บน production ผ่านปุ่ม Demo (รายงานข้อมูลรายวัน JV ปี 2569 + ใบสำคัญจากจอดูรายการ)
