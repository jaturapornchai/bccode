## 3. คำถามเปิดที่ต้องได้คำตอบจากลุงจืด

1. **ตัวเลขบัญชี**: currency, precision/scale ของเงิน/จำนวน/ต้นทุน/FX, rounding mode และจุดปัดเศษ, trusted source — ยังไม่มีคำตอบ แม้ GL จะเก็บเป็น `numeric(38,8)` แล้ว (KI-19)
2. **Backup**: platform, source/target, format, RPO/RTO, หลักฐาน backup ล่าสุด → ทำ drill ตาม `docs/runbooks/RECOVERY-READINESS.md`
3. **โค้ด ERP เดิมใน `goapi` ที่ไม่มีตารางรองรับ (KI-30)**: ลบทิ้ง หรือเก็บไว้รอสร้างโมดูลขาย/หนี้/สต็อกบน PostgreSQL

ปิดแล้ว (คำถามเดิมของรอบตรวจ 2026-09-07 หมดความหมายเพราะโค้ดที่เกี่ยวข้องถูกลบ 2026-09-23): quarantine package (ว่างแล้ว, KI-18); unit contract (โมดูล unit ถูกลบ); ถอด ClickHouse ถาวรหรือพักต่อ (ตัดสินแล้วว่าถอดถาวร); "PostgreSQL เพื่ออะไร" (ตอบแล้วโดยสถาปัตยกรรมใหม่ — PostgreSQL เป็นฐานเดียวของระบบ ไม่ใช่แค่ปลายทาง projection); organization outbox (โมดูล outbox ถูกลบทั้งหมด)
