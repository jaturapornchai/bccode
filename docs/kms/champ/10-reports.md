### 4.5 คำถามที่ต้องให้ลุงจืดตัดสิน

1. **ซ่อนกลุ่มรายงานของแต่ละโมดูลออกจากเมนู แล้วเหลือแต่ Report Center ตาม Champ หรือไม่** — Champ ซ่อนทุกกลุ่ม (§1.2) ; BC ตอนนี้โชว์กลุ่มรายงานในแต่ละโมดูล ซึ่งผู้ใช้ GL คุ้นแล้ว (ตัวเลือกกลาง: ทำ Report Center แล้วคงทางลัดในโมดูลไว้)
2. **ตัวกรองผู้ใช้ F9** (ผู้มีสิทธิ์เพิ่มช่องกรองเองต่อรายงาน) — ทำหรือไม่ (ข้อ 3 ใน §4.4)
3. **"คอลัมน์ของฉัน" (สูตรจากคอลัมน์อื่น)** — ทำหรือไม่ ; Champ ทำได้ แต่เป็นฟีเจอร์ขั้นสูงที่ใช้น้อย (ยังไม่มีข้อมูลการใช้งานจริง)
4. **ป้ายหัวรายงานพิมพ์ (Title / Page No. / Printed By / Printed Date / Description)** — Champ เป็นอังกฤษและพิมพ์ปี ค.ศ. ; BC ควรเป็นไทยและปี พ.ศ. ตามชนิดปีของบริษัท (`YearType`) หรือเหมือน Champ ทุกตัวอักษร
5. **ไม่มีข้อมูล** — Champ ว่างเงียบ ; BC แสดงข้อความ "ไม่พบข้อมูล..." (ผมแนะนำคงข้อความของ BC)
6. **ต้นแบบเรื่องรายงานซื้อซ้ำ** — `reportcenterconfig.xml` ของลูกค้าจริงไม่อยู่ใน repo : ผู้ใช้ Champ เห็นรายงานซื้อ 110 รายการ (PO 77 + โมดูล 10 33) หรือชุดใดชุดหนึ่ง ต้องขอไฟล์นี้จากลุงจืดถ้าจะลอกผังศูนย์รายงานให้ตรง
