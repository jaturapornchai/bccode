# ตรวจเมนู BC เทียบ Champ 5.5 (2026-10-09)

ลุงจืดสั่ง "ตรวจเมนูอีกรอบ ไม่แน่ใจเหมือน Champ หรือยัง" — ตรวจ 13 หัวเมนูบนสุดเทียบ **ภาพ dropdown จริง** ใน `D:\project-champ\bcspec\หน้าจอเมนู*\เมนู-ประกอบ*.jpg` (build `5.5 Pro # 20260709-12`) เป็นหลัก; `menuconfig.xml` ใช้เทียบรอง (ล้าสมัยกว่าภาพ ~20 รายการ: ไม่มี 4 รายการจัดซื้อ, ไม่มีเมนูย่อย "บันทึกซื้อสินค้าเชื่อ", ติดป้าย `disable=yes` ที่รายงานทั้งที่ภาพแสดงเมนูรายงานปกติ, ไม่มีหัวไฟล์/จัดการระบบ/หน้าต่าง/ช่วยเหลือเลย)

## ข้อสังเกตที่ขัดกับเอกสารเดิม
- `AGENTS.md` เขียนว่า `sale-reservation-flow` "มีใน Champ ห้ามตัด" แต่ภาพ dropdown จัดขาย build จริงไม่มีรายการ Flow/ตรวจสอบวันที่ใบสั่งขาย — มีเฉพาะ **ใบสั่งจองสินค้า** กับ **ใบสั่งจ่ายสินค้า** (BC ไม่มีทั้งคู่); ต้องให้ลุงจืดตัดสินว่าจะคง Flow เป็นส่วนเสริม (เกณฑ์ ADR `2026-10-09-champ-parity-purpose-additive-extras.md`) หรือเอาออก
- เมนูหัว จัดการระบบ/ไฟล์/หน้าต่าง/ช่วยเหลือ ของ BC ว่างเกือบหมด แต่หน้าจอบางส่วนมีอยู่ในหมวดตั้งค่า (`/holding/permission`, `/organization/role-permission` ฯลฯ) — ปัญหาคือ "หาไม่เจอในที่ที่ผู้ใช้ Champ เคยหา" ไม่ใช่ไม่มีฟังก์ชัน
- ข้อสรุป "Champ Parity 100%" ของ session เดิม (2026-10-07) ไม่ถูกต้องในระดับเมนู
