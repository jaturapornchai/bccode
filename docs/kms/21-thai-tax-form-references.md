## 0. กติกาของทะเบียนนี้

- ทุกช่องที่ระบบ **เติมให้ (prefill)** หรือ **คำนวณ (compute)** ในแบบภาษี ต้องมีแถวในทะเบียนนี้: แบบ/ข้อ → แหล่งทางการ (รหัสใน §1) → ถ้อยคำสั้นที่ใช้ตัดสิน → ข้อมูลในระบบที่ใช้ → โค้ด `path:line` → test
- ไม่มีแหล่งทางการ หรือข้อมูลในระบบไม่พอจะเติมโดยไม่เดา = **ไม่เติม** ปล่อยให้ผู้ใช้กรอก + มีหมายเหตุบอก (ดู §5) และเสนอลุงจืดถ้าควรเพิ่มข้อมูล
- ทุกช่องที่ระบบเติมยังแก้ได้เสมอ (ฐานภาษี/ยอดเครดิต) — ระบบคำนวณเฉพาะบรรทัดรวมตามสูตรบนแบบ
- แก้สูตร/ที่มาของช่องใด ต้องแก้แถวที่นี่ใน commit เดียวกับโค้ด

## 5. สิ่งที่ระบบยังไม่เติม เพราะข้อมูลไม่พอ (ห้ามเดา)

  - **มติลุงจืด 2026-09-23: "คงให้ผู้ใช้กรอกเอง"** — ช่องแยกบรรทัดเหล่านี้ให้ผู้ใช้กรอกเองต่อไป ไม่ทำตัวจับคู่อัตโนมัติ
  - **เทียบ Champ (`D:\project-champ`)**: ไม่มีแบบ ภ.ง.ด.50 และไม่มีตารางจับคู่ "บัญชี → บรรทัดแบบ"; งบการเงินของ Champ มาจาก "รูปแบบงบการเงิน" ที่ผู้ใช้ออกแบบเอง (`MyXpFinanceSheet.cpp` สูตร `ACC()`/`ACCGRP()`/`GETFS`) + "บันทึกกลุ่มผังบัญชี" (`BCAccGroup`); `BCChartOfAccount.AccountGroup` เก็บแค่หมวด 1–5
