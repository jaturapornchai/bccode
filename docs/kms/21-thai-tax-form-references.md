## 0. กติกาของทะเบียนนี้

- ทุกช่องที่ระบบ **เติมให้ (prefill)** หรือ **คำนวณ (compute)** ในแบบภาษี ต้องมีแถวในทะเบียนนี้: แบบ/ข้อ → แหล่งทางการ (รหัสใน §1) → ถ้อยคำสั้นที่ใช้ตัดสิน → ข้อมูลในระบบที่ใช้ → โค้ด `path:line` → test
- ไม่มีแหล่งทางการ หรือข้อมูลในระบบไม่พอจะเติมโดยไม่เดา = **ไม่เติม** ปล่อยให้ผู้ใช้กรอก + มีหมายเหตุบอก (ดู §5) และเสนอลุงจืดถ้าควรเพิ่มข้อมูล
- ทุกช่องที่ระบบเติมยังแก้ได้เสมอ (ฐานภาษี/ยอดเครดิต) — ระบบคำนวณเฉพาะบรรทัดรวมตามสูตรบนแบบ
- แก้สูตร/ที่มาของช่องใด ต้องแก้แถวที่นี่ใน commit เดียวกับโค้ด

## 5. สิ่งที่ระบบยังไม่เติม เพราะข้อมูลไม่พอ (ห้ามเดา)

- **ภ.ง.ด.50 รายการที่ 2–8 แยกบรรทัด** (รายได้โดยตรง/ต้นทุนขาย/รายได้อื่น/รายจ่ายขายและบริหาร/ต้นทุนผลิต ฯลฯ) และ **รายการที่ 9 แยกบรรทัด** (เงินสด/ลูกหนี้/สินค้า/เจ้าหนี้/ทุน/กำไรสะสม): คู่มือ RD-INS50-2566 ให้ "แยกประเภทตามรายการที่ปรากฏในแบบฯ ให้ครบถ้วนชัดเจน ห้ามแก้ไขหรือเพิ่มเติมรายการขึ้นใหม่" แต่ผังบัญชีตามสเปกของลุงจืด (`mydocs/datamodels/gl/chartofaccount.sql`) มีแค่หมวด 1–5 + ลำดับชั้น + `is_cash` — **ไม่มีข้อมูลว่าบัญชีไหนอยู่บรรทัดไหนของแบบ** ระบบจึงเติมเฉพาะกำไรสุทธิตามบัญชี (ข้อ 9) และยอดรวมงบ (`tax_form_fill.go:463`); จะเติมแยกบรรทัดได้ต้องให้ลุงจืดกำหนดการจับคู่ "บัญชี → บรรทัดแบบ" ก่อน ห้ามจับคู่จากชื่อ/รหัสบัญชีเอง
  - **มติลุงจืด 2026-09-23: "คงให้ผู้ใช้กรอกเอง"** — ช่องแยกบรรทัดเหล่านี้ให้ผู้ใช้กรอกเองต่อไป ไม่ทำตัวจับคู่อัตโนมัติ
  - **เทียบ Champ (`D:\project-champ`)**: ไม่มีแบบ ภ.ง.ด.50 และไม่มีตารางจับคู่ "บัญชี → บรรทัดแบบ"; งบการเงินของ Champ มาจาก "รูปแบบงบการเงิน" ที่ผู้ใช้ออกแบบเอง (`MyXpFinanceSheet.cpp` สูตร `ACC()`/`ACCGRP()`/`GETFS`) + "บันทึกกลุ่มผังบัญชี" (`BCAccGroup`); `BCChartOfAccount.AccountGroup` เก็บแค่หมวด 1–5
  - **ถ้าวันหน้าลุงจืดต้องการให้ระบบเติมแยกบรรทัด**: ต่อยอดจากของที่ BC มีแล้ว คือเมนู `gl-account-groups` (`/gl/account-groups`) และ `financial-statement-designer` (`/gl/statement-designer`) ให้ผู้ใช้กำหนดเอง — ไม่สร้างผังจับคู่ตายตัวในโค้ด
- **ภาษีถูกหักจากใบที่ไม่ได้บันทึกรายการภาษีหัก**: ไม่นับเป็นเครดิต (ไม่มีหลักฐานรายฉบับ) — ต่างจากจอรายงาน "ภาษีถูกหัก ณ ที่จ่าย" ซึ่งแสดงทั้งรายการที่บันทึก (recorded) และแถวที่ประมาณจากบรรทัดบัญชีภาษีถูกหัก (inferred, หาบัญชีจากชื่อที่มี "ภาษีถูกหัก" หรือ "ถูกหัก ณ ที่จ่าย") — แก้ 2026-09-23 ให้หาบัญชีมาตรฐาน "ภาษีเงินได้ถูกหัก ณ ที่จ่าย" เจอ และใบที่บันทึกรายการเข้ารายงานเสมอแม้ลงบัญชีชื่ออื่น (`backend/internal/goapi/handlers/tax_report.go` `buildWithholdingReport` + `recordedWithholdingRows`; test `TestWithholdingReceivedReport`) ดู §7 และ §9

- หัวแบบที่ยกจากฉบับก่อน (ที่อยู่/ผู้ลงนาม) ยกเฉพาะแบบตระกูลเดียวกัน: แบบของบริษัทจากแบบของบริษัท, ภ.ง.ด.93/94 (ผู้ยื่นบุคคลธรรมดา) จากแบบเดียวกันเท่านั้น (`copyProfile` ใน `tax_form_fill.go:178`; test `TestCopyProfileSameFamily`) — ถ้าทะเบียนบริษัทมีที่อยู่สำหรับภาษี (สำนักงานใหญ่) ที่อยู่ `addr_*` ที่ยกมาถูกล้างทั้งชุดแล้วใส่ของทะเบียน + โทรศัพท์เมื่อแบบมีช่อง ยกเว้นฉบับก่อนยื่นในนามสาขา (`branch_no` ไม่ใช่ 00000) (`applyRegistryAddress` `tax_form_fill.go:215`; test `TestApplyRegistryAddress`; ADR `decisions/2026-09-25-company-tax-address.md`)
