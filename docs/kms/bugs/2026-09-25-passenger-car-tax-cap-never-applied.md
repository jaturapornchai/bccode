# Symptom

รายงานกระทบยอดค่าเสื่อมราคาทางบัญชี-ทางภาษี (ภ.ง.ด.50, `GET /fa/v2/reports/tax-reconciliation`) ไม่เคยจำกัดค่าเสื่อมของรถยนต์นั่งที่ราคาทุนเกิน 1,000,000 บาท เมื่อสินทรัพย์ถูกสร้างจากหน้าจอหรือ MCP — ค่าเสื่อมทางภาษีเท่ากับทางบัญชี ผลต่างที่ต้องบวกกลับเป็น 0

# Root Cause

1. `reports.go` เช็คเพดานจาก `AssetTypeCode == "PASSENGER_CAR"` แต่ปุ่มแม่แบบในฟอร์มบันทึก `VEHICLE_PASSENGER` และช่องประเภทเป็นข้อความอิสระ (ผู้ใช้ตั้งรหัสเอง) — รหัสไม่ตรงกันจึงไม่เข้าเงื่อนไขเลย; MCP `fa_create_asset` ก็ไม่มีทางบอกได้ว่าเป็นรถยนต์นั่ง
2. แม้เข้าเงื่อนไข สูตรเดิมให้ 200,000 บาทตายตัว (20% × 1 ล้าน) แล้วจำกัดไม่เกินค่าเสื่อมบัญชี — ปีที่ซื้อกลางปีและปีสุดท้ายจึงหักเกิน (รวมตลอดอายุเกิน 1 ล้าน) และผิดเมื่ออัตราทางบัญชีต่ำกว่า 20%
3. ข้อยกเว้นตามกฎหมาย (รถของกิจการให้เช่ารถ, รถยนต์ต้นแบบวิจัย — พ.ร.ฎ. 145 ม.5) เป็นรายคัน จึงตัดสินจากรหัสประเภทไม่ได้ตั้งแต่ต้น

# Fix

- เพิ่ม `passengercartaxcap` (bool) ที่ตัวสินทรัพย์ (`Asset.PassengerCarTaxCap`) — ผู้ใช้ติ๊กเอง; ปุ่มแม่แบบ "รถยนต์นั่งไม่เกิน 10 ที่นั่ง" ติ๊กให้ แม่แบบอื่นเอาออก; MCP `fa_create_asset` รับ param เดียวกัน
- ค่าเสื่อมทางภาษี = ค่าเสื่อมบัญชีของปี × 1,000,000 ÷ ราคาทุน (ปัด 2 ตำแหน่ง) ตามข้อหารือ กค 0702/5605 ("คำนวณหักตามระยะเวลาที่ได้ทรัพย์สินนั้นมา")
- ที่มาทางกฎหมาย + ถ้อยคำที่ใช้ตัดสิน: [[21-thai-tax-form-references]] §13

# Regression Test

- `backend/internal/fixedasset/tax_reconciliation_test.go` — สร้างจาก JSON แบบที่ฟอร์มส่ง (`VEHICLE_PASSENGER` + flag), เต็มปี ≈ 200,000, ซื้อ 1 ก.ค. = สัดส่วน, รหัส `PASSENGER_CAR` ที่ไม่ติ๊ก (รถกิจการให้เช่า) ไม่ถูกจำกัด, ราคาทุน 900,000 ไม่ถูกจำกัด
- `backend/internal/fixedasset/mcp_create_asset_test.go` — สร้างผ่าน `fa_create_asset` แล้วรายงานถูกจำกัด (อยู่ใน test binary เดียวกับ package หลัก เพราะถ้าแยก package สองโปรเซสจะชนกันตอน `CREATE TABLE IF NOT EXISTS fa_records`)
- ทั้งสองเทสต์ fail กับโค้ดเดิม (ภาษี = บัญชี 299,999.97) — ต้องมี `BC_GL_TEST_POSTGRES_DSN` (`tools/verify.sh postgres`)
