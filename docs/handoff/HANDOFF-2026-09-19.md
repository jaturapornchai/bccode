## 3. งานค้างให้ Gemini ทำต่อ (เรียงตามความสำคัญ ตอบเลขเดียวเริ่มได้)

- **[1] (แนะนำ) ทำ API + จอให้รายงาน Champ ที่ค้าง 31 รายการ ทีละโมดูล เริ่ม AP/AR** — ปัญหา: เมนูมีแต่กดแล้วเจอ "รอพัฒนา" — Scope: backend Go (`backend/internal/goapi/...` report handlers บน PostgreSQL per-holding) + `frontend/src/lib/erp-reports.ts` (เพิ่ม config route/code/columns เมื่อ API มีจริง) + ลบ route ออกจาก `pendingRoutes` ใน `menu-screen-status.ts`. รายการ pending ทั้งหมดดูจาก `npx vitest run src/lib/menu-screen-status.test.ts` (test แสดง 31 route) หรือ id ใน ADR §C. **ห้ามแต่ง column/API code ก่อน backend มีจริง (NO MAGIC)**
- **[2] Speed Entry (Tab / Enter / Numpad) ในตารางสินค้าหน้าขายและซื้อ** — ปัญหา: คีย์เอกสารยังต้องใช้เมาส์ ไม่ลื่นเหมือน Champ desktop — Scope: `frontend/src/app/crud/erp-crud-workbench.tsx` ใช้ `frontend/src/hooks/use-tabular-enter-nav.ts` ที่ทำไว้ให้ GL แล้ว (แถวสุดท้าย+ช่องสุดท้าย → auto-insert แถวใหม่)
- **[3] จำหน่ายสินทรัพย์แบบ Champ (ในทะเบียนสินทรัพย์ ไม่แยกเมนู)** — ปัญหา: วันนี้ตัดเมนู `asset-disposal` ออกแล้ว ผู้ใช้จำหน่ายสินทรัพย์บน UI ไม่ได้ — Scope: `frontend/src/app/asset/fixed-assets-screen.tsx` (เพิ่ม action ในแถวสินทรัพย์) + backend resource `disposals` มีอยู่แล้ว (`frontend/src/lib/fixed-assets.ts` type `AssetDisposal`)
- **[4] กวาด dead code ที่ flag ไว้นอกขอบเขต** — `frontend/src/lib/fixed-assets.ts` type `AssetDisposal`/`FACommand.disposal` (จะกลับมาใช้ถ้าทำ [3]), branch ตายใน `general-ledger-screen.tsx` เดิม (`/gl/allocations`, `/tools/databackup`, `/report/xbrl`) — ตรวจก่อนลบว่าไม่มี reference
- **[5] i18n ต่อสายไฟ (th/en เท่านั้น)** — ยังมี hard-code ไทยในหลายจอ (audit 2026-09-14: ~137 ไฟล์) และ backend `fmt.Errorf("ไทย")` ~294 จุด — ทำเฉพาะ key + th + en ห้ามแปลภาษาอื่น

## 4. วิธีทำงาน / คำสั่งประจำ

```bash
# ตรวจก่อน commit ทุกครั้ง (ไม่มี CI — ต้องรันเอง)
cd frontend && npx tsc --noEmit && npx vitest run && npx eslint src --quiet && npm run build
# หรือรวม
npm run verify            # codemap + frontend lint/typecheck/test
npm run verify:all        # + backend (ช้า ก่อน deploy)
# hooks (ทำครั้งเดียวต่อ clone)
npm run hooks:install
# code map เมื่อแตะไฟล์ใหญ่
pwsh -NoProfile -File tools/gen-code-map.ps1
# deploy (frontend อย่างเดียว / ทั้งคู่)
py tools/fast-deploy.py --tag rYYYYMMDD-<name>
py tools/fast-deploy.py --all --tag rYYYYMMDD-<name>   # ต้องใช้ --all ถ้าแก้ languages.tsv (อยู่ใน image mainapi)
```

- Commit ต้องมี `README.md` (activity log) ในคอมมิตเดียวกัน — hook ปฏิเสธถ้าไม่มี; ข้ามเฉพาะกรณีจำเป็น `SKIP_README_CHECK=1`
- ก่อนเปลี่ยนแปลงใหญ่: commit + push checkpoint ก่อน (rollback ได้)
- ฐานข้อมูลทุก env เป็น disposable (pre-launch) — เปลี่ยน schema/จอ/ฟิลด์ได้ไม่ต้องถาม ยกเว้น deploy/push/force ที่เป็น R0
