## 2. กฎเหล็ก 8 ข้อ (ผิดข้อไหนถือว่างานไม่ผ่าน)

1. **ห้ามเดา** — ไม่รู้ business rule/ตัวเลข/สูตรบัญชี ให้ **ถามลุงจืด** ห้ามแต่งเอง; docs บอกว่าโค้ด*ทำอะไร* ไม่ใช่ว่า*ควรทำอะไร*
2. **ห้ามบอก "เสร็จ" ถ้ายังไม่ verify** — ต้องแปะผลรันจริง (output/screenshot/query) ไม่ใช่ "น่าจะ work"
3. **แก้ให้เล็กที่สุด** — งาน 1 บรรทัด = แก้ 1 บรรทัด; เจอบั๊กอื่นระหว่างทาง → **บอกก่อน อย่าแก้เอง**
4. **ห้ามสร้าง workflow ใน `.github/` ใหม่** และห้ามย้าย `backend/.github/workflows/*.yaml` ขึ้นมาที่ root (ดู §4-D)
5. **ห้ามทำระบบเงินเดือน** — payroll, ภ.ง.ด.1, ภ.ง.ด.1ก, ไฟล์ประกันสังคม อยู่นอกขอบเขตสินค้า (`AGENTS.md` มีรายละเอียด); แต่ **ภ.ง.ด.2/3/53 อยู่ในขอบเขต** ห้ามลบทิ้งเพราะเข้าใจผิด
6. **งาน UI ต้องอ่าน `docs/skills/ui-scale-polish/SKILL.md` จาก disk ก่อนเสมอ** และจบงานต้องอัปเดต skill นั้นใน commit เดียวกัน (ผู้ใช้จริงคือคนไทยอายุ 40+ — ตัวใหญ่ ไทยก่อน คอนทราสต์สูง ปุ่มใหญ่)
7. **ห้าม hardcode secret** และห้าม commit `.env*`, `bootstrap*.json`, `custom_config*.json`
8. **อ่านไฟล์ใหญ่แบบเจาะจงบรรทัด** — ไฟล์ >1,000 บรรทัดดูตำแหน่งจาก `docs/reference/CODE-MAP.md` ก่อน (แต่ต้องเทียบ `wc -l` ยืนยันก่อนเชื่อเลขบรรทัด)

## 5. กับดักที่ทำให้ AI พลาดซ้ำ ๆ (เจอจริงในเซสชันวันนี้)

1. **แก้ shell script ขณะที่มันกำลังรันอยู่** → bash อ่านไฟล์ทีละส่วน จะพังกลางคัน (`syntax error near unexpected token`) — รอให้จบก่อนแก้
2. **อ้างเลขบรรทัดในเอกสารแล้วไปแก้ไฟล์นั้นทีหลัง** → เลขเลื่อนทั้งหมด ต้องแก้ไฟล์ให้นิ่งก่อน ค่อยเขียนเลขบรรทัดลง docs แล้ว**ตรวจซ้ำ**
3. **regex แทนที่เลขบรรทัดแบบกวาด** → ไปโดนเลขบรรทัดของไฟล์อื่นด้วย ใช้การแทนที่แบบระบุข้อความเต็มพร้อม assert จำนวนครั้ง
4. **ไฟล์ EOL/BOM ผสม** — `.gitignore` เป็น CRLF, `tools/gen-code-map.ps1` มี BOM (ต้องมี ไม่งั้น PowerShell 5.1 อ่านภาษาไทยเพี้ยน), `frontend/src/app/globals.css` ผสม CRLF/CR/LF → แก้ด้วยสคริปต์ที่รักษาไบต์เดิม อย่าใช้ editor ที่ normalize ทั้งไฟล์
5. **`frontend/next-env.d.ts` เด้งเอง** — `next dev` กับ `next build` เขียนคนละค่า ให้ `git checkout -- frontend/next-env.d.ts` ก่อน commit
6. **เชื่อผลของ subagent โดยไม่ตรวจ** — subagent ตัวหนึ่งวันนี้เตือนว่า PowerShell 5.1 รัน `gen-code-map.ps1` ไม่ได้ พอทดสอบจริงกลับรันได้ปกติ **ต้อง verify เองก่อนเขียนลง docs เสมอ**
