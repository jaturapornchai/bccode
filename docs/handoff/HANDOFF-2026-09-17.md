## 2. งานที่ต้องทำต่อ — เรียงตามความสำคัญ

### 2.1 (ด่วน) กับดัก schema ค้างบนเครื่องจริง — ปิดถาวรด้วยโค้ด 1 บรรทัด
`DatabaseChecker` (`backend/internal/goapi/process/build/create-database.go:1773`) รันเฉพาะ `CreateShop` (`backend/internal/shop/shop_http.go:160`) และตอนเอกสารวิ่งผ่าน Kafka (`backend/internal/goapi/handlers/utils.go:112`) — holding ที่สร้างก่อน DDL ใหม่จะขาดตาราง (prod `demo` เคยไม่มี `stock_ledger` → รายงานขาย 500) จนกว่าจะมีเอกสารใบแรก
ทำ: เรียก `build.DatabaseChecker(ctx.UserInfo().HoldingCode, false)` ตอนต้นของ `ResyncDebtor`/`ResyncCreditor` (`backend/internal/debtaccount/*/..._http.go`) และ `POST /product/resync` — idempotent และ cache ต่อ process อยู่แล้ว; ตรวจโดย drop ตาราง `stock_dirty` ใน PG local `demo` แล้วยิง resync → ตารางต้องกลับมา (บทเรียน: `docs/kms/17-dev-gotchas.md` แถวสุดท้าย)

### 2.2 path ที่หน้าจอ ERP ยิงแล้ว 404
`frontend/src/lib/erp-transaction.ts` มี `apiPath` ที่ backend ไม่มี route: `billingnote` (:309), `bank/saledebitnote` (:206), `bank/purchasedebitnote` (:285), `bank/banktransferrecord` (:423, :774), `bank/depositrecord` (:478), `chequereceive/chequedeposit` (:434), `chequepayment/chequepaymentdeposit` (:445) — ไม่มีโฟลเดอร์ `backend/internal/transaction/{billingnote,bank,chequereceive,chequepayment}`
ก่อนเขียนใหม่: โมดูล `saledebitnote`, `purchasedebitnote`, `banktransferrecord`, `depositrecord`, `chequedeposit`, `chequepaymentdeposit` **มีอยู่แล้ว** ที่ `/transaction/<ชื่อไม่มี prefix>` (ดู `RegisterHttp` ในแต่ละ `*_http.go`) — ถ้าตรงกัน แก้ `apiPath` ฝั่ง frontend ให้ตรง (ถูกกว่าเขียน backend ซ้ำ) เหลือที่ต้องเขียนจริงคือ `billingnote` (ใบวางบิล) — ดูต้นแบบใน `D:\project-champ` ก่อน (กฎ Champ) แล้วทำตามแพตเทิร์น `receivableother` (header `transmodels.TransactionHeader` + stamp businesscode + goapi consumer ถ้าต้องถึง PG)
ตรวจ: `node tools/probe-endpoints.mjs transaction` ต้องไม่มี 404 ที่ path เหล่านี้

- Go build/vet (Windows build ตรงไม่ได้เพราะ kafka CGO): `MSYS_NO_PATHCONV=1 docker run --rm -v "$(cygpath -m "$PWD")/backend:/src" -w //src golang:1.26 sh -c "go build ./... && go vet ./..."`

- **prod** (`root@159.223.43.229`): PG `docker exec bcai-account-postgres-1 psql -U bcai -d demo`, Mongo `docker exec bcai-account-mongo-1 mongosh bcai_account`, เรียก API ภายในด้วย `docker exec bcai-account-frontend-1 node --input-type=module -e "..."` ไป `http://mainapi:8888` (mainapi ไม่มี curl); DLQ: `docker logs --since 10m bcai-account-mainapi-1 | grep -c "DLQ MESSAGE"`
