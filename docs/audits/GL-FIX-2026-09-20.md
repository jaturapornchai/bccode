## ข้อจำกัดที่ยังคงตั้งใจ

- THB, scale ตามปีบัญชี, ไม่ FX/net AR-AP/ส่งเงินจริง/RD Prep/XBRL.
- รายการเก่าที่ไม่มี details ยังไม่มีข้อมูลคู่ค้า/Statement ต้องเติมจากหลักฐานจริง.
- Missing period rows ยังคงอนุญาตเพื่อให้บริษัทเดิมใช้งานได้; หากมีงวด locked/ปี closed จะบังคับ guard.
- Process close/year-end สร้าง draft closing/opening ตาม flow เดิม ผู้ใช้ต้องตรวจและผ่านรายการ.
- Process ทั้งบริษัทใช้ `CompanyWide` จาก grant ล่าสุด; preview ส่ง `companywide=true` เพื่ออ่านขอบเขตเดียวกัน. การเลือกสาขาบนจอไม่ลดสิทธิ์ระดับบริษัทที่มีอยู่ แต่สิทธิ์เฉพาะสาขาไม่ถูกยกระดับ. Legacy token ที่ผูกสาขายังใช้ process/preview ทั้งบริษัทไม่ได้; token ระดับบริษัทคง company allowlist และ readonly/readwrite เดิม.
- การเปลี่ยน schema เพิ่มตารางใหม่; rollback image ไม่ควร drop ตารางหลักฐานหรือแก้ข้อมูลผ่านรายการย้อนหลัง.
- รายงานยอดค้างย้อนหลังใช้ทั้งวันบัญชีและวันเกิด/ถอนหลักฐาน; วันที่อ่านแสดงบนผลลัพธ์.
- ยังไม่ได้ประเมินว่าบั๊กเดิมเคยถูกใช้กับข้อมูลจริงไปแล้วนอก baseline บริษัทนี้.
