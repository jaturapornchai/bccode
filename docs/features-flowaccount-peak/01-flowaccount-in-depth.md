# เมนูและความสามารถของ FlowAccount

ตรวจแหล่งข้อมูล: 2026-09-07 | ขอบเขต: งานธุรกิจ บัญชี ภาษี การเงิน สินค้า และสินทรัพย์ ไม่รวมระบบเงินเดือนและ HR

รวบรวมจาก[คู่มือและแหล่งทางการ](https://flowaccount.com/help-center) โดยเลือกเฉพาะรายการที่มีแหล่งอ้างอิงของผลิตภัณฑ์นี้ใน[บัญชีเมนูฉบับละเอียด](09-flowaccount-peak-menu-catalog.md) ไม่รวมแบบจำลองฐานข้อมูลหรือสเปกพัฒนาระบบที่ออกแบบเอง

พบหลักฐานในตารางเทียบเคียง 130 รายการ ตัวเลขนี้รวมการทำงาน รายงาน ตั้งค่า และช่องทางเสริม ไม่ใช่จำนวนเมนู sidebar หรือหน้าจอที่ไม่ซ้ำ และไม่แปลว่ารายการที่ไม่อยู่ในตารางนี้ไม่มีในผลิตภัณฑ์

รหัสชนิด: M = หน้ารายการ/เมนู, A = การทำงานภายในหน้า, R = รายงาน/มุมมอง, S = ตั้งค่า, C = ช่องทางเชื่อมต่อ ชื่อเป็นชื่อกลางเพื่อเทียบเคียง หลักฐานบางรายการเป็นหน้ารวมคู่มือ รายละเอียดขอบเขตและสิทธิ์ยังต้องตรวจบทความเฉพาะเรื่องหรือบัญชีใช้งานจริง
