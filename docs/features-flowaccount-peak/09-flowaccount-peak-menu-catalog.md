# รายการเมนูและความสามารถ — FlowAccount + PEAK Account

วันที่ตรวจแหล่งข้อมูล: 2026-09-07  
ขอบเขตล่าสุดจากลุงจืด: รวมงานธุรกิจ บัญชี การเงิน ภาษี สต็อก และสินทรัพย์ของทั้งสองระบบ **ไม่เอาระบบเกี่ยวกับเงินเดือน**

## 1. ขอบเขตและวิธีอ่าน

เอกสารนี้รวบรวมเฉพาะเมนูและความสามารถของ FlowAccount กับ PEAK Account จากคู่มือทางการ จัดหมวดเพื่อเทียบเคียงกัน ไม่ใช่สเปกพัฒนาระบบใหม่ และยังไม่ได้ตรวจเมนูหลังล็อกอินครบทุกบทบาทหรือแพ็กเกจ

**ตัดออกทั้งหมด:** FlowPayroll, PEAK Payroll, ทะเบียนพนักงานเพื่อทำเงินเดือน, HR, เวลาเข้าออกงาน, การลา, ค่าจ้าง, เงินเพิ่ม/เงินหักของพนักงาน, สลิป, ไฟล์จ่ายเงินเดือนธนาคาร, ประกันสังคม, กยศ., ภ.ง.ด.1/1ก และ 50 ทวิของพนักงาน รายงานและการเชื่อมต่อเงินเดือนก็ไม่อยู่ในขอบเขต ไม่มีแผนทำในระยะถัดไปของงานนี้

**ยังคงไว้:** ภาษีหัก ณ ที่จ่ายของคู่ค้า/ผู้ให้บริการ, ภ.ง.ด.3/53, หนังสือรับรองหัก ณ ที่จ่ายธุรกิจ, ผู้ใช้งานและสิทธิ์เข้าโปรแกรม, แผนกในฐานะมิติรายได้/ค่าใช้จ่าย และชื่อผู้ขายในฐานะข้อมูลอ้างอิงเอกสาร สิ่งเหล่านี้ไม่ต้องพึ่งระบบ HR

หลักการนับและหลักฐาน:

- `M` = หน้ารายการหรือเมนูย่อยที่จัดหมวดในเอกสารนี้
- `A` = ปุ่มทำงาน/ขั้นตอนภายในหน้า ไม่ถือเป็นเมนูด้านซ้ายแยกโดยอัตโนมัติ
- `R` = รายงานหรือมุมมองวิเคราะห์
- `S` = หน้าตั้งค่าหรือส่วนตั้งค่า
- `C` = ช่องทาง/ผลิตภัณฑ์เชื่อมต่อ ไม่ใช่เมนูบัญชีหลัก
- `[Fxx]` = พบความสามารถในแหล่งทางการ FlowAccount; `[Pxx]` = พบใน PEAK
- มีแหล่งเพียงค่ายเดียว = ยืนยันได้จากค่ายนั้นในรอบนี้ **ไม่ได้แปลว่าอีกค่ายไม่มี**
- ชื่อและการจัดหมวดในตารางใช้ชื่อกลางภาษาไทยเพื่อเทียบเคียง ไม่อ้างว่าเหมือนชื่อ sidebar ของทั้งสองระบบทุกตัว
- หลักฐานจากหน้ารวมคู่มือยืนยันว่ามีหัวข้อการใช้งานนั้น แต่รายละเอียดสิทธิ์ แพ็กเกจ สถานะเอกสาร และผลลงบัญชีต้องตรวจบทความรายเรื่องหรือบัญชีใช้งานจริงเพิ่มเติม
- รหัส `01.01` เป็นต้นเป็นรหัสอ้างอิงภายในเอกสาร ไม่ใช่รหัสเมนูหรือรหัส API ของผู้ให้บริการ

สรุปขนาดรายการ: 18 หมวด 243 รายการความสามารถ ประกอบด้วยหน้ารายการ/เมนูย่อย 72 รายการ, การทำงานภายในหน้า 63 รายการ, รายงาน/มุมมอง 55 รายการ, ตั้งค่า 34 รายการ และช่องทาง/ผลิตภัณฑ์เชื่อมต่อ 19 รายการ ตัวเลขนี้รวมทางลัดรายงานที่ระบุไว้ จึงไม่ใช่จำนวนหน้าจอไม่ซ้ำหรือจำนวน sidebar ของคู่แข่ง

## 2. หมวดสำหรับเทียบเคียงเมนู

| หมวด | ชื่อเมนูหลัก | ขอบเขต |
|---|---|---|
| 01 | ภาพรวมกิจการ | ยอดขาย รายจ่าย เงินคงเหลือ และภาพรวมผู้บริหาร |
| 02 | ขายและเอกสารรับเงิน | เสนอราคา ส่งของ แจ้งหนี้ ใบกำกับ รับเงิน มัดจำ ลดหนี้ เพิ่มหนี้ |
| 03 | ซื้อและรับสินค้า | สั่งซื้อ รับสินค้า/บริการ รับแจ้งหนี้ มัดจำ และเอกสารปรับหนี้ฝั่งซื้อ |
| 04 | ค่าใช้จ่ายและการจ่ายเงิน | บันทึกค่าใช้จ่าย จ่ายทันที/ตั้งเจ้าหนี้ รายการประจำ และเอกสารประกอบ |
| 05 | ลูกหนี้และเจ้าหนี้ | ค้างรับ ค้างจ่าย อายุหนี้ วางบิลรวม รับเงินรวม และรวมจ่าย |
| 06 | เงินสด ธนาคาร และเช็ค | ช่องทางเงิน โอนระหว่างบัญชี เงินสำรอง เช็ค และไฟล์โอนธุรกิจ |
| 07 | กระทบยอด | Statement รายการในบัญชี จับคู่ และตรวจผลต่าง |
| 08 | สินค้า บริการ และคลัง | ข้อมูลสินค้า คงเหลือ เคลื่อนไหว โอน เบิก คืนเบิก และต้นทุน |
| 09 | สินทรัพย์ | ทะเบียน ซื้อ ขาย ค่าเสื่อม และงานระหว่างก่อสร้าง |
| 10 | ภาษีธุรกิจ | ภาษีซื้อ ขาย หัก ณ ที่จ่าย และเอกสารอิเล็กทรอนิกส์ |
| 11 | บัญชีและปิดงวด | ผังบัญชี สมุดรายวัน แยกประเภท งบทดลอง ปรับปรุง และล็อกงวด |
| 12 | โครงการและ BOQ | โครงการ มิติข้อมูล ปันส่วน และประมาณปริมาณ/ราคางาน |
| 13 | คลังเอกสารและสแกนบิล | รับไฟล์ OCR ตรวจข้อมูล และเชื่อมเอกสารต้นฉบับ |
| 14 | ลูกค้าและคู่ค้า | สมุดรายชื่อ กลุ่มผู้ติดต่อ เครดิต และข้อมูลผู้ติดต่อหลัก |
| 15 | รายงาน | ศูนย์รวมรายงานเอกสาร บัญชี การเงิน ภาษี สินค้า และสินทรัพย์ |
| 16 | ขายหน้าร้าน | แคชเชียร์ รับชำระ พักบิล และเอกสารขายหน้าร้าน |
| 17 | การเชื่อมต่อ | ร้านค้าออนไลน์ API ระบบภายนอก มือถือ และช่องทางแชท |
| 18 | ตั้งค่าและศูนย์ช่วยเหลือ | กิจการ ผู้ใช้ เอกสาร นโยบายบัญชี แพ็กเกจ และคู่มือ |

หมวดเหล่านี้ใช้จัดกลุ่มหลักฐานจากสองระบบ ไม่ใช่ลำดับ sidebar จริงของแต่ละระบบ ชื่อเมนูและตำแหน่งอาจต่างกันตามผลิตภัณฑ์และสิทธิ์

## 4. ประเด็นที่ยังต้องยืนยัน

| เรื่อง | สิ่งที่ตรวจพบ/ยังต้องยืนยัน | ผลต่อขอบเขต |
|---|---|---|
| เมนูหลังล็อกอินทุกแพ็กเกจ | ตรวจคู่มือสาธารณะ ยังไม่ได้เข้าระบบแต่ละบทบาท/แพ็กเกจ | ยังไม่รับรอง sidebar ตรงครบ 100% |
| แพ็กเกจและสิทธิ์รายเมนู | คู่มือระบุเงื่อนไขต่างกัน และบางหน้าเป็น Old PEAK | ต้องทำตารางสิทธิ์จากระบบจริงก่อนรับรอง parity |
| Bank Rules ที่ตั้งเองได้ | พบ Bank Feed และกระทบยอด แต่ยังไม่ได้หลักฐานตัวสร้างกฎชื่อ/เงื่อนไขจากเอกสารเดิม | ไม่เพิ่มเป็นเมนูยืนยันแล้ว |
| FIFO เทียบ Average | พบการคำนวณต้นทุนและล็อตใน PEAK แต่ยังไม่ตรวจบทความวิธีคำนวณรายผลิตภัณฑ์ครบ | ยังไม่สรุปว่านโยบายของสองระบบเหมือนหรือต่างกันทุกกรณี |
| Serial/Lot ผลิต/วันหมดอายุ | ล็อตต้นทุนไม่ใช่หลักฐานระบบ batch tracking; serial สินทรัพย์ไม่ใช่ serial สต็อก | ยังไม่เพิ่มเป็นความสามารถสต็อกยืนยันแล้ว |
| หลายคลัง PEAK | แหล่งที่อ่านยืนยันรายละเอียดหลายคลังฝั่ง FlowAccount | ช่อง PEAK ยังรอยืนยัน ไม่เขียนว่าไม่มี |
| POS offline/กะ/คืนเงิน | คู่มือที่ตรวจยังไม่ยืนยันทุกขั้นตอน | เก็บเป็นหัวข้อค้นต่อก่อนขยายหมวด 16 |
| OCR ของ PEAK | พบคลังเอกสารและหน้าฟังก์ชันตัวช่วยคีย์ แต่ยังไม่ตรวจรายละเอียดชนิดเอกสารและขั้นตอน OCR | ยังไม่ระบุว่าเทียบ AutoKey ได้ทุกแบบ |
| e-Tax/e-Withholding | มีคู่มือการเชื่อมต่อ ไม่ได้แปลว่ามีสิทธิ์ยื่นแทนหรือเชื่อมทุกธนาคาร | ตรวจสัญญาและบริการจริงก่อนทำ integration |
| ภ.ง.ด.50/51/54 และภาษีอื่น | ภ.ง.ด.54 พบคู่มือบันทึกธุรกรรม; ยังไม่ยืนยันเมนูสร้างแบบครบ | ไม่กล่าวว่าโปรแกรมจัดการภาษีทุกชนิดอัตโนมัติ |
| All-in-One/Webhook/Schema | ไม่ตรวจ API reference ในงานบัญชีเมนูนี้ | ห้ามนำชื่อ endpoint/DDL ในเอกสารที่ยังไม่ยืนยัน ไปอ้างเป็น API ทางการ |
| ระบบผลิต/MRP/บัญชีรวมกลุ่ม | ไม่ได้ยืนยันจากรายการคู่มือที่อ่าน | ไม่เพิ่มเป็นฟีเจอร์มาตรฐานโดยอนุมานจาก ERP/หลายกิจการ |
