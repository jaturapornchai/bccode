# FlowAccount + PEAK Account — ฟีเจอร์และเมนู

โฟลเดอร์นี้เก็บเฉพาะข้อมูลผลิตภัณฑ์ ฟีเจอร์ เมนู และการเปรียบเทียบ **FlowAccount กับ PEAK Account** จากแหล่งทางการ ไม่รวมระบบเงินเดือน/HR ไม่รวมสเปกพัฒนาระบบใหม่หรือแบบจำลองฐานข้อมูลที่ออกแบบเอง

ตรวจแหล่งข้อมูลล่าสุด: 2026-09-07

## เอกสาร

| ไฟล์ | เนื้อหา |
|---|---|
| [01 — FlowAccount](01-flowaccount-in-depth.md) | รายการที่พบหลักฐานฝั่ง FlowAccount แยกหมวด พร้อมลิงก์ทางการ |
| [02 — PEAK Account](02-peak-account-in-depth.md) | รายการที่พบหลักฐานฝั่ง PEAK Account แยกหมวด พร้อมลิงก์ทางการ |
| [03 — ตารางเปรียบเทียบ](03-comparative-matrix.md) | เทียบหลักฐานของสองค่ายทีละรายการ ไม่เหมารวมว่ายังไม่ยืนยันเท่ากับไม่มี |
| [09 — เมนูและความสามารถฉบับละเอียด](09-flowaccount-peak-menu-catalog.md) | 18 หมวด 243 รายการ แยกเมนู งาน รายงาน ตั้งค่า ช่องทาง และข้อจำกัด พร้อมแหล่งทางการ 35 หน้า |

เลขไฟล์เดิมคงไว้เพื่อความต่อเนื่อง ไม่ต้องเติมไฟล์หมายเลขที่เว้นไว้

## ขอบเขต

ขายและรับเงิน, ซื้อและรับสินค้า, ค่าใช้จ่าย, ลูกหนี้/เจ้าหนี้, เงินสด/ธนาคาร/เช็ค, กระทบยอด, สินค้า/บริการ/คลัง, สินทรัพย์, ภาษีธุรกิจ, บัญชีและปิดงวด, โครงการ/BOQ, คลังเอกสาร/OCR, ผู้ติดต่อ, รายงาน, POS, การเชื่อมต่อ และตั้งค่า

ภาษีหัก ณ ที่จ่ายของคู่ค้า ภ.ง.ด.3/53 และสิทธิ์ผู้ใช้ยังอยู่ในขอบเขต ส่วนเงินเดือน พนักงานเพื่อคำนวณค่าจ้าง การลา ประกันสังคม และภาษีเงินเดือนถูกตัดออก

## การใช้หลักฐาน

- เริ่มจาก 09 เมื่อต้องการดูรายละเอียดครบ หรือ 03 เมื่อต้องการเทียบสองค่าย
- ชื่อในตารางเป็นชื่อกลางสำหรับเทียบเคียง ไม่รับรองว่าตรง sidebar ทุกแพ็กเกจและบทบาท
- 243 เป็นรายการความสามารถรวมขั้นตอนและทางลัด ไม่ใช่ 243 หน้าจอไม่ซ้ำ
- จำนวนรายการใน 01 และ 02 ทับซ้อนกันได้ เพราะทั้งสองค่ายมีความสามารถร่วมกัน
- สิ่งที่ยังไม่ยืนยันแยกไว้ชัดเจน ไม่ถือว่าผลิตภัณฑ์ไม่มีความสามารถนั้น
- ไม่ใช้คู่มือฟีเจอร์อนุมานชื่อ table, schema, enum, endpoint หรือสถาปัตยกรรมฐานข้อมูลภายใน

แหล่งหลัก: [FlowAccount Help Center](https://flowaccount.com/help-center) และ [PEAK คู่มือการใช้งาน](https://www.peakaccount.com/peak-manual)
