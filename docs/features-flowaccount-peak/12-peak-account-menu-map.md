# ผังเมนูและงานในหน้า — PEAK Account

ตรวจเมื่อ 2026-09-07 | ไม่รวมระบบเงินเดือนและ HR

## วิธีอ่านและขอบเขตความครบ

ผังนี้จัดเมนูและงานในหน้าตามชื่อที่พบในคู่มือ PEAK แยกจากชื่อกลางใน[บัญชีเมนู 09](09-flowaccount-peak-menu-catalog.md) และตรวจหน้ารวมคู่มือ **15 หมวดในขอบเขต** ดัชนีลิงก์ครบตามหน้าที่เข้าถึงอยู่ใน[13 — หลักฐานการไล่คู่มือ](13-peak-manual-coverage.md)

ตารางหมวดงานรวมทั้งหน้ารายการ ปุ่ม แบบพิมพ์ และผลิตภัณฑ์เสริม จึงไม่ใช่การยืนยันว่าทุกแถวเป็น sidebar หนึ่งหน้า แถว “เส้นทางที่ยืนยัน” ด้านล่างเท่านั้นที่คงลำดับการกดจากบทความรายเรื่อง ส่วนหมวดคู่มือช่วยตรวจความครอบคลุมของงาน ยังไม่ได้ล็อกอินตรวจสิทธิ์และหน้าจอทุกแพ็กเกจ

การใช้งาน: เลือกหมวดงาน → เปิดบทความหรือเส้นทางยืนยัน → เทียบรายการใน 09 → ตรวจแท็บ/ปุ่มที่เปลี่ยนตามสถานะและสิทธิ์ก่อนนำไปอ้างอิง ตำแหน่งใน Old PEAK ต้องแยกจาก New PEAK

## แท็บและปุ่มที่ไม่ควรตกหล่น

ใบเสนอราคามีแท็บ **ล่าสุด, ทั้งหมด, ร่าง, รออนุมัติ, รอตอบรับ, พ้นกำหนด, ยอมรับแล้ว, ออกบางส่วน, ออกครบแล้ว, ปฏิเสธแล้ว, ยกเลิก** โดย “ล่าสุด” แสดง 100 รายการ และปุ่มแถบล่างเปลี่ยนตามสถานะ [คู่มือสถานะ](https://www.peakaccount.com/peak-manual/sales-document/create-quote/check-quotation-document-status)

เอกสารรับ/จ่ายมีสถานะกลุ่ม **ร่าง, รออนุมัติ, รอรับชำระ/เกินเวลารับชำระ/รับชำระแล้ว และรอจ่ายชำระ/เกินเวลาชำระ/ชำระแล้ว** แต่ไม่ควรคัดลอกทุกสถานะไปใช้กับทุกชนิดเอกสาร รายละเอียดสถานะและผลลงบัญชีอยู่ใน[คู่มือสถานะเอกสาร](https://www.peakaccount.com/peak-manual/peak-others/other-related-documents/understanding-document-statuses)

| เครื่องมือร่วม | สิ่งที่ต้องครอบคลุม | แหล่ง |
|---|---|---|
| รายการโปรด | ต้นแบบเสนอราคา แจ้งหนี้ ใบเสร็จ และค่าใช้จ่าย | [ขาย](https://www.peakaccount.com/peak-manual/sales-document), [รายจ่าย](https://www.peakaccount.com/peak-manual/purchase-document) |
| คัดลอกเอกสาร | เริ่มรายการใหม่จากข้อมูลเดิมตามชนิดที่รองรับ | [คู่มือเครื่องมือเอกสาร](https://www.peakaccount.com/peak-manual/peak-others) |
| พิมพ์/ดาวน์โหลด/ส่งอีเมล/ลิงก์ | ตัวเลือกส่งออกหน้ารายละเอียด | [คู่มือเครื่องมือเอกสาร](https://www.peakaccount.com/peak-manual/peak-others) |
| พิมพ์หลายใบ | สูงสุด 100 รายการ/ครั้งตามคู่มือ มีทางเลือกดาวน์โหลดหรือส่งอีเมล | [พิมพ์หลายรายการ](https://www.peakaccount.com/peak-manual/peak-others/other-related-documents/print-multiple-docs) |
| แท็กและค้นหา | เพิ่ม/ลบแท็ก ค้นตามแท็ก และรายงาน | [คู่มือเครื่องมือเอกสาร](https://www.peakaccount.com/peak-manual/peak-others) |
| ล็อกรายใบ | ล็อก/ปลดล็อก รวมผลกับบันทึกบัญชี; เอกสารที่คู่ค้ายอมรับมีข้อจำกัดเพิ่ม | [ล็อกเอกสาร](https://www.peakaccount.com/peak-manual/peak-others/other-related-documents/lock-documents-by-item) |
| แก้ไข/ยกเลิก | ต่างกันเมื่อมีเอกสารต่อเนื่อง ชำระแล้ว หรือถูกล็อก | [ขาย](https://www.peakaccount.com/peak-manual/sales-document), [ซื้อ](https://www.peakaccount.com/peak-manual/purchase-document) |

| แจ้งเตือน/ประวัติ | งานรออนุมัติ ผลดาวน์โหลด และประวัติส่งเอกสาร | [พิมพ์หลายรายการ](https://www.peakaccount.com/peak-manual/peak-others/other-related-documents/print-multiple-docs), [ประวัติอีเมล](https://www.peakaccount.com/peak-manual/peak-others/document-review/troubleshooting-email-history-on-documents) |

### 15. ข้อจำกัดที่ต้องแยกจากเมนู

- ใบขอซื้อ/ขอจ้าง/ขออนุมัติจ่ายที่พบเป็นรูปแบบพิมพ์จากใบสั่งซื้อ ยังไม่ยืนยัน workflow ขอซื้ออิสระ
- รวมหลายใบแจ้งหนี้เป็นใบกำกับใบเดียว: คู่มือระบุว่าทำตรงไม่ได้ ต้องผ่านใบวางบิลและใบเสร็จที่เกี่ยวข้อง ไม่สร้างชื่อเมนู “รวมใบกำกับ” ขึ้นเอง [คู่มือ](https://www.peakaccount.com/peak-manual/sales-document/sales-tax-invoice/combine-invoices-to-single-tax-invoice)
- คู่มือปิดงบระบุว่าไม่มีปุ่มปิดงบการเงิน ใช้ตรวจงบทดลอง/ปรับปรุง/ดูงบ จึงเก็บเป็นขั้นตอนงาน [คู่มือ](https://www.peakaccount.com/peak-manual/peak-others/other-related-documents/close-financial-statement)
- การย้ายจำนวนระหว่างรหัสสินค้าเป็นการประยุกต์ปรับจำนวน ไม่ยืนยันเมนูโอนคลัง [คู่มือ](https://www.peakaccount.com/peak-manual/inventory-management/edit-initial-products-services/stock-reallocation)
