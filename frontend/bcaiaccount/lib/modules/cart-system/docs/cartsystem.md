### ระบบตระกร้าสินค้า (Cart System)
## จุดประสงค์: เพื่อสร้างระบบตระกร้าให้สามารถนำไปใช้ในระบอื่นๆ ได้ เช่นระบบสั่งซื้อ ระบบเสนอราคา เป็นต้น
- สร้างเฉพาะระบบตระกร้า (Cart System) ที่แยกออกจากระบบอื่นๆ ไม่ต้องสร้างระบบสั่งซื้อ ระบบเสนอราคา
- เน้นให้ระบบตระกร้า สามารถนำไปใช้ร่วมกับระบบอื่นๆได้ง่าย
- เน้นให้ระบบตระกร้า มีประสิทธิภาพสูง รองรับการใช้งานจำนวนมาก
- ระบบค้นหาสินค้าเป็นแบบ Full Text Search ตัดคำภาษาไทยด้วย แล้วเอา Array ไปใช้ในการค้นหา เพื่อให้ค้นหาสินค้าได้แม่นยำขึ้น
- ค้นหาสินค้าใน multiple fields: `name0` (ชื่อสินค้า), `unitname` (ชื่อหน่วย), `unitcode` (รหัสหน่วย), `barcode` (บาร์โค้ด), `itemcode` (รหัสสินค้า)
- Thai Word Tokenizer แยกคำภาษาไทยและภาษาอังกฤษเป็น Array แล้วค้นหาด้วย OR operator เพื่อความแม่นยำสูง หาใน name0,unitname,unitcode,barcode,itemcode

# file ที่เกี่ยวข้อง อยู่ใน folder lib/modules/cart-system
- ภาษา Flutter/Dart: lib/modules/cart-system/cartsystem.dart หน้าจอหลัก
- สวยงาม ใช้งานง่าย

## โครงสร้างข้อมูล เป็นแบบ JSON ใช้ Database NoSQL ในการจัดเก็บข้อมูล (MongoDB):
- Cart: เก็บข้อมูลตะกร้าสินค้า เช่น รหัสตะกร้า, รหัสผู้ใช้, สถานะตะกร้า
- CartItem: เก็บข้อมูลรายการสินค้าในตะกร้า เช่น รหัสรายการ, รหัสตะกร้า, รหัสสินค้า, จำนวนสินค้า, ราคาต่อหน่วย
- แยกตระกล้าตาม Email ผู้ใช้ เพื่อความง่ายในการเข้าถึงข้อมูล
- ในแต่ละ Email ผู้ใช้ สามารถมีตระกร้าได้หลายตระกร้า (เช่น ตระกร้าสำหรับสั่งซื้อ, ตระกร้าสำหรับเสนอราคา)
- ให้ MongoDB จัดการการเกี่ยวกับตระกร้า รายการสินค้าในตระกร้า และอื่นๆ เป็นรูปแบบ JSON Document อันเดียวเลย
- MongoDB 

## Steps การทำงานของระบบตะกร้าสินค้า:
- เมื่อกด Icon ตระกร้า จะเปิด Tab ใหม่ สำหรับระบบตะกร้าสินค้า (เหมือนกดสร้างหน้างานใหม่)
- เปิดหน้าจอจะเห็นรายการสินค้าเลย 
- ด้านขวาบน (AppBar) มี Icon ตระกร้า ถ้าไม่มีให้แสดง "ยังไม่มีตระกร้า" ถ้ามีการเลือกตะกร้าแล้ว ให้แสดงชื่อตะกร้าที่เลือกอยู่ พร้อมจำนวนรายการสินค้าในตะกร้า
- ถ้ากดที่ Icon ตระกร้า จะเปิดหน้าจอแสดงตะกร้าสินค้าทั้งหมดของผู้ใช้ และมีปุ่มเพิ่มตะกร้าใหม่
- สามารถเพิ่มตะกร้าใหม่ได้ โดยมีรายละเอียดตะกร้าคือ ชื่อตะกร้า แค่นั้น
- เมื่อกด Save ถือเป็นการเลือกตะกร้าใหม่นั้นเลย แล้วกลับมาหน้าจอเลือกสินค้าทันที
- ไม่มี Tab Navigation, ไม่มี Popup Overlay - ทุกอย่างอยู่ในหน้าเดียว สลับไปมาระหว่างหน้ารายการสินค้ากับหน้ารายการตะกร้า

## ฟีเจอร์หลัก ระบบเลือกตะกร้าสินค้า:
- สร้างตะกร้าใหม่
- แสดงตระกร้าทั้งหมดของผู้ใช้
- แก้ไขตะกร้า
- ลบตะกร้าสินค้า

## ฟีเจอร์ ระบบค้นหาสินค้าเพื่อเพิ่มลงในตะกร้า:
- สินค้าอยู่ในระบบฐานข้อมูล ClickHouse เชื่อต่อผ่าน API
- ระบบค้นหาสินค้าสินค้าเพื่อเพิ่มลงในตะกร้า
- มี Text Search สำหรับค้นหาสินค้า
- เมื่อกดค้นหาแล้ว ให้แสดงรายการสินค้าที่ตรงกับคำค้นหา
- สามารถเลือกสินค้าที่ต้องการเพิ่มลงในตะกร้าได้
 
## ฟีเจอร์ ระบบจัดการรายการสินค้าในตะกร้า:
- ลบสินค้าออกจากตะกร้า
- แก้ไขจำนวนสินค้าภายในตะกร้า
- ดูรายการสินค้าทั้งหมดในตะกร้า
- คำนวณราคารวมของสินค้าทั้งหมดในตะกร้า
- เปลี่ยนสถานะตะกร้า (เช่น จาก "กำลังดำเนินการ" เป็น "สั่งซื้อแล้ว")

## ClickHouse API:
- ฐานข้อมูลสินค้าอยู่ใน ClickHouse
- ใช้ ClickHouse SELECT API ในการดึงข้อมูลสินค้า
- table {CH_DATABASE_NAME}.productbarcode เป็น table หลักที่ใช้เก็บข้อมูลสินค้า (dev: bcbidev, prod: bcbi)
- fields shopid,itemcode,barcode,name0,unitcode,unitname,price1,unitstand,unitdivide
- unitstand และ unitdivide เป็นอัตราส่วนการแปลงหน่วย เช่น 1 แพ็ค มี 12 ชิ้น = unitstand=12, unitdivide=1 หรือ ชิ้น:ชิ้น = unitstand=1, unitdivide=1
