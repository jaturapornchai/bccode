## CRITICAL (6)
1. **/googlelogin account takeover** — backend trusts a posted `email` and mints a token with NO Google ID-token verification (`GoogleLoginRequest` has no idToken field); posting the owner email → owner token. Public path blocked by the denylist stopgap, BUT mainapi binds `0.0.0.0:8888` (`docker-compose.yml`) so any host on the .202 LAN hits it directly. Fix: verify a real Google ID token server-side (idtoken.Validate, check aud/iss/exp/email_verified, derive email from claims); bind mainapi to 127.0.0.1. `authentication_http.go:400`, `authentication_service.go:979`, `models/authentication.go:33`.
2. **Cross-tenant PG read/write via `database` body field** on `/goapi/get` + `/goapi/exec` — the tenant guard (`bootstrap.go:361/392`) only inspects `holdingcode`/`tenantid` keys, never `database`; handler connects `PgSqlFastConnect(payload.Database)` with no check that it equals the token tenant. Any authed user reads/writes ANY tenant's PG DB. Also: duplicate `holdingcode` key in guard list (bug), `allowedSelectTables` is dead code. Fix: derive tenant DB SOLELY from the token (`userInfo.HoldingCode`), ignore body `database`, or 403 on mismatch. `database.go:137/316`.
3. **NoSQL injection + cross-tenant read via `/reportm/playground`** — body `Filter` is `UnmarshalExtJSON` (operators preserved) on an arbitrary `collection`, and holdingcode is NEVER added to the filter. Any shop user dumps any tenant's collection (shopusers, etc.). `ExecuteReportQuery` shares the missing-filter defect (lower, stored query). Fix: force `filters["holdingcode"]=holdingCode` last; whitelist collections; reject `$where`. `reportquery_http_service.go:246`.
4. **Cross-tenant + raw-SQL via MCP `/invoke`** — `server.go:1141` only fills holdingcode when blank, so a caller-supplied holdingcode passes through to ClickHouse query (`fmt.Sprintf` → SQLi) and to `executepgcommand` (`PgSqlFastConnect(holdingCode)` → arbitrary SELECT/UPDATE/DELETE/DROP). dev tools missing from `WriteTools` so default keys reach them. Fix: force `holdingcode = apiKey.HoldingCode` unconditionally (match SSE path); gate dev tools owner-only; parameterize/validate. `server.go:1141/1789`, `dev_database.go:52`, `clickhouse_query.go:216`.
5. **Unauthenticated bootstrap.json secret dump** — `/goapi/api/setup/config/get-raw` (+`config/get`) on the no-auth group `g`, gated only by `verifySetupPassword()` which defaults to **"12345"** when no password doc exists; returns all secrets in plaintext (DB creds, MongoDB Atlas URI, Groq/OpenRouter/Cloudflare keys, JWT secret if deployed). Publicly reachable (allowlisted in `api/setup/[...setupPath]/route.ts` AND via catch-all). Fix: mask secrets in `config/get`, remove the "12345" fallback, put setup behind owner auth, drop from public proxy, **rotate ALL secrets**. `setup_config_handler.go:208/266`, `loader.go:476`.

## HIGH (5)
7. **Any tenant member self-mints MCP key with `['*']` tools** (no owner/admin gate) → reaches dev raw-SQL tools via key-only `/mcp/dev/sse`. Fix: owner/admin gate on key creation; separate dev tier; add dev tools to WriteTools. `mcp_apikey_handler.go:52`, `permissions.go:5`.
8. **MCP API key RNG is non-crypto time-based** — `charset[time.Now().UnixNano()%62]` in a tight loop → all 32 chars collapse to ~1 value (empirically: 11/12 keys distinct=1). Effective keyspace ~62, brute-forceable in <1 min once any key exists. Fix: `crypto/rand`. `auth/middleware.go:193`.
9. **Cross-tenant IDOR on MCP key endpoints** — `GetAPIKeyByID` queries `_id` only (no holdingcode); `/export` returns the plaintext key → cross-tenant key theft (Get/Update/Delete also affected). Fix: add `holdingcode` to the lookup / compare `userInfo.HoldingCode`, return 404 on mismatch. `mcp_apikey_handler.go:463`, `keys_repo.go:112`.
10. **SQL injection in `/goapi/getdoc`** — `search`/`fromdate`/`todate`/`custcodes` raw `fmt.Sprintf` into WHERE, run via `db.Query` (no validateSelectQuery). Authenticated, tenant-scoped. Fix: parameterize ($1…, pq.Array). `getdoc.go:180-251`.
11. **Unauthenticated LINE webhook, attacker-chosen tenant** — no X-Line-Signature HMAC check; tenant from query/header; each request fires an unbounded goroutine (Mongo writes + AI cost). Default rate-limiter bypassable via spoofed XFF (no trusted-proxy). Fix: verify HMAC vs per-tenant ChannelSecret; resolve tenant from verified payload; worker pool; BodyLimit; IPExtractor. `lineoa/chatbot.go:27`.

## MEDIUM (3)
12. **goapi guard fails-open for ClickHouse handlers** + SQLi (`clickhouse.go:127`) — latent (CH `ClickHouseFastConnect` stubbed disabled now); live cross-tenant read the moment CH is re-enabled. Fix: per-handler tenant binding + parameterize + fail-closed guard.
13. **Unescaped `$regex`** (ReDoS / index-bypass scan DoS) on `/product/barcode?q=` + ~9 MCP search tools — raw keyword into `$regex` (the canonical `regexp.QuoteMeta` path is bypassed). Tenant-scoped (no leak), availability/CPU only. Fix: `QuoteMeta` + length cap + shared helper + maxTimeMS. `productbarcode_http.go:1380`.

Fix: soft-delete via the same CrudRepository path. `units.go:501`, `barcodes.go:822`, `product_categories.go:431`, `product_groups.go:480`.

A denylist extension (block `/backend/goapi/get|exec|getdoc`, `/backend/reportm`, `/backend/goapi/api/setup`, `/backend/goapi/api/mcp`, `/backend/goapi/mcp`) is a fast R2 stopgap, but verify the frontend doesn't legitimately use those paths first.
